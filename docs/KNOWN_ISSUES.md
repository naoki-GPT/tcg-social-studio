# 引き継ぐ問題と改善条件

## 現在あるもの

原本を基にした配布版の制作スキル2.2.0、第1工程スキル1.0.0、HTMLからの静止画・無音動画出力、参考との比較、全フレーム解析の補助、入力と完成条件の検査。外部収集サービスの専用手順・コードを削除し、ローカル素材の取り込みへ変更しています。

第2工程の草案5ファイルは別に保存しました。検査コードは書きかけで、記録ひな形との項目不一致も残っています。インストール済み・検証済みとは扱えません。市場調査の取得原本や実ユーザーの前提記録は取り込んでいません。

## 改善する内容

| 問題 | 現在の事実 | 完了条件 |
|---|---|---|
| Museでの素材用意 | 収集サービスの専用コード・手順は削除済み。ローカル素材の受け取りを実装 | Muse側で公開情報／許可済みファイルから必要な全素材を用意し、1企画の受け渡しを実証する |
| 商品が買いたい理由になっていない | 有名キャラ、相場表、単なる言語比較では不十分との利用者評価 | 対象市場の需要、同条件の比較、費用を踏まえた得、具体的なDM／リンク行動がつながる |
| 参考の文字の分析が浅い | 何を伝えて何をさせるのかが不明瞭との評価 | 全文と各場面を読み、欲求・利益・根拠・反論への答え・行動を対応させた分析がある |
| デザイン再現が不足 | REF-005等は専用HTMLがあるが書体・背景等に未再現部分がある | カルーセル全枚・動画全編を比較し、配置、効果、モーション、字幕の時刻まで照合。近似は明示 |
| 画像生成の接続 | モデルの希望はあるが、配布先共通の呼び出しアダプターはない | Muse側のCodexで利用可能な生成手段を確認し、入力・出力・失敗時の扱いを実装 |
| 動画の音・実映像 | 既存レンダラーは静止画像＋HTMLの無音動画用 | 音・実映像が必要な企画では、対応する編集経路を実装・同期検証 |
| 工程間の受け渡し | 第1工程の形式はある。第2工程は草案、第3工程以降の独立化は未実施 | 各工程で入力、成果物、判定、差し戻し先が明確になる |
| Muse連携 | 機能と認証、Codex依頼、ファイル受け渡しは未確認 | Muse側で制作一往復を実測し、接続方法を文書化 |
| 管理表と承認・投稿 | 新しい管理先・SNSアカウント・連携コードは未設定 | 指定先の読み戻し、版にひも付く承認、重複投稿防止、投稿後の確認が動く |

## 再開時に守ること

作成者固有の収集環境で得た市場件数を「配布先でも確認できた根拠」へ読み替えない。2026-11-13のゲンガーex・ピカチュウex・コイキングの比較は確定企画にしない。いずれも市場・状態・費用条件を新しい標準手順で確認する。

元の公開参考URLや索引は同梱されていますが、参考画像・動画の全原本、書体ファイル、利用者の商品素材は同梱されていません。URLや設計メモだけで取得・目視済みとしない。必要なファイルと使える範囲を案件ごとに確認してください。

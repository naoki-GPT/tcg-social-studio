# 共通試作の引き継ぎ前提

2026-11-13。利用者との会話で決まった内容と、第1工程で置いた仮案を分けた引き継ぎです。既知の内容を初回質問へ戻さず、仮案は仮案として調査を始めてください。

## 決まっていること

- 鈴木さん・河合さんの両方に使える制作フローの共通試作を、1企画だけ作る。
- 改善する目的は、現在の需要と具体的な買う理由を示し、DMでの相談や商品ページ閲覧などの行動につなげること。
- 工程を一つずつ具体化し、成果物と次へ進む条件を確認する。原稿・デザインへ一気に流さない。
- 河合さん専用の参考リール再現は別件。鈴木さんの管理スプシとその保存済み台帳コピーは使わない。
- 共通試作に特定店の在庫・売価・送料・発送・DM対応実績を補わない。
- 調査と制作をMuse側で改善する。作成者だけが使える外部収集サービスへの依存は削除済み。

## 後で決めるもの

商品、採用参考、静止画／カルーセル／動画、枚数と尺、店名・実際のDM先や購入リンク、販売条件、管理表・投稿先はまだ決めていません。参考ZIPがあることを理由にREF-005や特定カードへ固定しません。

ゲンガーex・ピカチュウex・コイキングの以前の比較案は確定企画ではありません。別の取得環境で得た市場データを、Muse環境で検証できた根拠として採用しないでください。過去に不評だったコダック175/165等へ戻す場合も、需要と具体的な買う理由を新しい根拠で確認します。

## 素材待ちで止める工程を限定する

目的設計・前提整理・現在の需要調査・制作プログラムのオフライン検査は、参考ZIPの受領前でも進められます。原本は参考の全文分析・全編分析から必要です。

商品画像は商品選定後、同じ書体の確認は参考の分解時、管理表と投稿先の設定は外部連携時に必要になります。まだ必要でない入力を集め終わるまで全工程を止めないでください。

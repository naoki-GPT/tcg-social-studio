## 確認したことと限界

全原本は保存時の取得記録の順序・枚数・SHA256と一致。画像デコード、動画の全編映像／音声デコード、ZIPのCRCと展開内容の一致、12件すべての入力形式とファイル存在を確認しました。

容量対応では画像・動画・音声の変換を行っていません。分割前の全58ファイルが両ZIPにそろい、各ファイルのバイト列が同じであることと、それぞれ25,000,000 bytes未満であることを確認しました。

元投稿へ再訪しての再確認、今回の全文分析、全編目視、音声聴取は未実施です。音声トラックがあることと、内容を聞いて確認したことを混同しません。付属本文は保存時点の元投稿者の主張で、現在価格・現在需要・自社条件・直近の伸びの証拠にはなりません。

# trial-001 納品・検査報告

固定依頼によるREF-003型4枚カルーセルの共通試作。制作・全4枚の書き出し・比較・目視確認まで実施。販売用完成ゲートには未合格。外部への投稿・送信なし。変更はtrial-001内のみ。

## 成果物

- `reference-breakdown.json`：原本4枚の文字・寸法・役割・設計・置換・未解決差分
- `recipe-card.json`：4:5、4枚の編集カード（最終テキスト座標を実測反映）
- `content.json`：指定文・価格・商品画像、brand=TRIAL、draft=false
- `05_caption.md`：指定英語本文と全文日本語訳
- `production/index.html`：編集用HTML。`content.js`・`recipe.js`・同名JSON・assets/・build.jsonを同梱
- `production/slides/01.png`〜`04.png`：最終PNG各1080×1350、`slides_check.json`
- `compare/compare_001.jpg`：原本と最終PNGの全4組比較、`compare.json`、`compare_notes.md`
- `production-contract.json`：試作であることと根拠・不足を明記した完成契約
- `production/acceptance.json`：指定完成検査の実結果
- `production/recipe-check.json`、`technical-check.json`、`content-check.json`、`visual-review.md`：検査記録
- `reference/01.jpg`〜`04.jpg`：検査契約用原本コピー（元販売者の情報は参照資料内にのみ保持）
- `selection-review.json`：固定入力と独立市場検証の区別
- `trial-template.html`、`build_trial.py`、`make_trial.py`、`finish_trial.py`、`inspect_trial.mjs`、`contact_sheet.py`、`chrome-trial`：制作・環境補完スクリプト

## 未解決差分と意図した変更

- 未解決：全ページの原書体が未特定、approx。1枚目の祝祭背景は平面的なCSS表現で、原本の装飾・質感に一致しない。
- 意図した変更：12商品→指定4商品2×2。見出し・価格・日付・商品差し替え。2〜4枚目は元店の実績・商品カタログ・注文条件を完全に除外し、指定の根拠／見積項目／DM案内へ置換。元店名・ロゴを完成面に使用していない。
- 依頼固定の価格・成約文章を保持し、独立した新規市場検証は実施していない。実店舗の店名・アカウント・実条件、素材利用条件、実際の投稿UIは未確認。販売用完成・公開済みとは扱わない。
- コダックは元画像の解像感が他3点より低い。外周黒余白のみCSSでクリップし、カード全体・番号・著作権行を保持した。

## 再書き出し

`production/index.html`と`production/content.js`を編集可能。既存出力を上書きしない仕様のため、再書き出し先は新しいフォルダ名を指定する。

```bash
TCG_NODE_MODULES=/opt/hatch/skills/spaces/ts-runtime/dist/node_modules CHROME_PATH="$PWD/chrome-trial" FFMPEG_PATH=/usr/bin/ffmpeg node ../studio-skill/scripts/export_slides.mjs production/index.html --out production/slides-v2 --ratio 4:5
```

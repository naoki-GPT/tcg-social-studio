# 需要と買う理由を取り違えない

## 証拠の段階

| 種類 | 確認できること | 残る限界 |
|---|---|---|
| primary_sold_detail | 元出品本文の販売済み表示と商品条件 | 決済・返品・購入者の国や職業は通常不明 |
| primary_sold_search | 市場の販売済み検索に掲載された記録 | タイトルだけの状態判定や、元本文未確認を残す |
| secondary_sale | 集計サイトに載った成約情報 | 誤分類・遅延・同じ出品の重複。元出品に戻って照合 |
| official_sales_aggregate | 運営者の実売集計 | 対象期間・地域・言語・状態・金額順か数量順かを照合 |
| asking_price | 現在の掲載額 | 成約額・自社売価・必要数量を確保できる証拠ではない |
| cumulative_sold | 単一出品の累計販売表示 | 期間不明なら30日販売数に含めない |

`eBay.com`、USD表示、出品者所在地だけで購入者が米国居住と確定しない。米国出品者の成約を米国市場の手掛かりとする場合は推測として説明する。店舗・業者が買った実績とも断定しない。

元本文が読めなくても一次の販売済み検索を確認できた場合は、その範囲の証拠として使える。NMというタイトル表記は状態の保証ではない。`condition_basis: title` とし、元画像・本文まで読んだ扱いにしない。品質差が解消していない比較で節約率を広告に出さない。

## 行ごとの除外・保留

- 言語・版・番号・商品種別が違う、PSA等の鑑定品、まとめ売り、損傷品、AS IS、期間外、指定市場の代理条件に合わない行は対象群から除外。
- 状態・数量・成約確認が不明なら保留。明示のない送料を0円にせず、`free`の表示がある場合だけ0として扱える。
- Best Offerの成立自体は需要の証拠になり得るが、金額が非公開なら価格中央値から外す。取得データに売価の欄があっても打消し値・値幅・元の提示額の可能性を確認する。
- 同じ出品IDを重複計上しない。別IDでも同一売り手への偏りを記録する。同じカード写真を使った再出品の可能性は残る。
- 各候補の取得上限、採用・除外・保留行数を残す。上限到達の標本から売上速度・市場シェア・月販を推定しない。
- 直近7日と30日で価格を比べても、抽出方法・状態・売り手構成が違う場合は値動きの確定指標にしない。

## 買い手が検討できる条件

同じ日本語版の国内と海外、別言語の対応カード、同じ商品の時点差の3種類を混ぜない。為替・価格種別・日付・送料・状態の対応を残す。

販売店向けの検討例：

`仕入れ総額の上限 = 想定販売額 − 販売費用 − 買い手が残したい金額`

`日本側掲載額以外に使える額 = 仕入れ総額の上限 − 日本側掲載額の通貨換算`

後者には国際送料、国内送料、輸入費用、決済、仕入れ手数料、販売者側の取り分も収まる必要がある。正の数でも取引成立や利益を保証しない。買い手に提示する総額見積りと国内市場の掲載額は別物。

目標粗利率や仮の費用率は事業者の実績ではなく比較条件。相場下落・円高・小口送料で余地が消える場合も示す。条件を変えたら再計算する。個人収集家向けなら再販利益ではなく、予算・絵柄・状態・入手性など、その客が買う理由を同じ粒度で検証する。

## 保存する最小単位

元URL・取得時刻・データが表す時点・取得方法・保存ファイルとSHA256、商品ID、出品ID、売り手、掲載成約日、言語・状態・鑑定・数量と判断根拠、価格種別・通貨・送料、採用可否と理由。

この記録の`facts_allowed`には実際に言える主張だけを入れる。件数は「今回取得した標本のうち」と限定し、店の在庫・現在売価・必ず儲かる・世界一人気などを補わない。

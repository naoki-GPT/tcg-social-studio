# 4.1.0 — 2026-11-14

毎日3案を作って人が選ぶ形にし、表を5タブの1つのスプレッドシートにまとめた。

## 変えたこと

- **毎日3案（リール1・カルーセル1・画像1）を作る。** 3案は商品も型も別にする。人は気に入った案にだけチェックを入れる。選ばれなかった案は「ストック」として7日間使える。
- **チェックした案だけを投稿する手順を足した**（references/publish.md）。投稿後の数字の記録もここに含む。
- **表を5タブにした。** 投稿／素材／参考帳／今週の候補／数値の記録。人が見るのは「投稿」だけ。各タブの「見た目」欄に画像を出し、アドレスを開かなくても中身が分かるようにした。
- **画面の文字（英語・日本語訳）を表に書く。** 画像・動画の中の文字も、本文と同じく英語と日本語訳をそろえる。
- **手本は「参考帳」タブから選ぶ。** 最初の60件入り（うち、そのまま作れるもの30件）。週1回、新しい手本を足す。
- **商品の調査を週1回にまとめた**（references/weekly.md）。毎日は「今週の候補」から選んで、今日の価格を取り直すだけ。
- **在庫の有無を商品選びの条件から外した。** 投稿の目的を「問い合わせ・DM・コメントをしてもらうこと」と明記した。
- **リールは、実写の参考をカード画像で作り替えるのを基本にした。** 構成とテンポを借り、見た目は型カードで決める。
- **型カード（7種類）と動きの部品集を足した**（references/types.md、templates/parts/）。完成した動画の見本は手本にしない。
- **需要・価格・買う理由の3枚を「商品を決める」1枚に、再現と本文の2枚を手順の順に書き直した。**

# 4.0.0 — 2026-11-14

毎日、人に質問せずに投稿の直前まで進める形へ組み直した。動画・画像の作り方の決めと、素材を全ページ・全編そろえる決めは 3.0.0 のまま。

## 変えたこと

- **人に聞く手順をなくした。** 前提確認の別スキル（tcg-social-intake）、制作前の4点確認、候補を人に見せて採用を待つ手順を廃止。止まるのは「client.json の必須欄が空」と「投稿・送信」だけ。
- **相手ごとに変える場所を client.json の1枚にまとめた。** 店名、アカウント、スプレッドシートのアドレス、保存先、売る国、問い合わせの受け口、締めの出し方。商品の種類・合言葉・色は毎回スキルが決めて表に残す。
- **人が見る場所を表の1タブにした。** 1企画1行、人は「投稿OK」にチェックを1つ入れるだけ。3枚あった記録表（投稿／検証・改善／投稿数値）は「投稿」1枚に。
- **素材は自分で取りに行く。** 参考投稿は自分のブラウザーで開いて全ページ・全編を保存し、`import_reference.py` で順番・枚数・重複を確かめて取り込む。取れなければ別の参考へ移る。
- **本体を「毎日の流れ」だけにした。** 細かい決めは工程ごとの説明書へ移し、各工程で読むのは1〜2枚。過去の指摘の経緯は本体から外した。
- **道具を、受け取ったPC（Windows）でそのまま動く形にした。** 作成者の環境の場所の直書きをなくし、動画ごとの値は引数と `cues.json` で渡す。ブラウザーはPCの Chrome／Edge を使う。
- **効果音29個を同梱した。** 取りに行く手順は不要。
- **ファイル名を半角英数字にそろえた。** 日本語のファイル名が展開時に文字化けして、説明書から開けなくなっていたため。
- **完成契約・作り方カード・検査スクリプト群を、検品の説明書1枚（8項目）にまとめた。**

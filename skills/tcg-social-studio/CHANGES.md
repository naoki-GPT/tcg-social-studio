# 5.1.0 — 2026-11-20

同業者6アカウントの直近の投稿168本を、商品ごとに数えた調査を受けて、商品の決め方と、作る前の流れを変えた。

- **毎回、その日の動きを調べてからネタを出す。** 調べるのは5つ：公式の発売の予定／同業者の直近7日の投稿／海外で売れたもの（直近7日）／国内の値動き／表の「聞かれた商品」。きのうまでの候補を使い回さない。
- **商品の候補に「なぜ今か」を付ける。** 区分は `新弾・予約`／`同業者が出している`／`聞かれた`／`海外で売れ出した`／`国内で値が動いた`／`定番`。ネタは、この順に近いものから選ぶ。
- **新弾・予約の商品は、30日の売れた記録が無くても候補に入れてよい**（予約か発売直後に売れた記録が1件、または同業者2アカウント以上が出している）。
- **新弾・予約と、同業者が今出している商品は、日付と価格が変われば毎日出してよい。** それ以外の商品は、今までどおり3日以内に繰り返さない。
- **ネタを5つ出し、人が選んだものだけ作れるようにした**（`client.json` の `plan_approval` を `chat` にしたとき）。ネタはチャットに出し、選ばれるまで画像も動画も作らない。直しの指示もその場で受ける。返事が無い日は作らない。`off`（書いていないときもこちら）は今までどおり、聞かずに `daily_set` の数だけ作る。前の版のまま使っている相手は、欄を足さなければ今までと同じ。
- ネタの数は `plan_count`（既定5）。未開封BOXとまとめ売りを半分以上、シングルかPSA鑑定品を1つ以上、リール・カルーセル・画像を1つ以上ずつ入れる。
- **ワンピースカードを扱えるようにした**（`client.json` の `games` に `onepiece` を足したとき）。
- **表にタブを2つ足した。**「同業者の動き」（同業者の投稿を1投稿1行で残す）と「聞かれた商品」（DMなどで聞かれた商品を人が書く。空でもよい）。「商品の候補」タブに「発売日」「なぜ今か」の列を足した。前の版の表には、AIがタブと列を足す。
- 「買う言葉のコメント」は記録として残すが、型や商品を選ぶ根拠にしない（同業者でも168本中129本が0件で、比べられなかった）。選ぶ根拠は「聞かれた商品」にする。
- `reference_accounts` に3件足した（`kyoshop_poken.jpn`、`beclearjapan`、`pokeparceljp`）。
- **海外で売れた記録がまだ無い商品（発売前の新弾など）は、自分の価格を出さない。** 発売日と、予約の見積もりの受付と、頼み方で作る。
- ネタには、同業者が同じ商品に出している価格を並べて書く。自分の見積もりとの差が分かるようにする。
- 公式の発売日が前後7日以内の商品は、同業者が出していなくても候補に入れてよい。
- ネタに出す価格は、今日読んだものだけにする。見積もりの元は、今日買える一番安い出品（成約の平均ではない）。
- 価格表（B）のネタは、商品を3つ以上並べる。
- ネタに付ける画像のアドレスは、作るときに使う正規の画像にする。
- 海外で売れた記録は PriceCharting で読む。eBay は機械からの読み取りを拒むので開かない。

# 5.0.0 — 2026-11-19

同業者の投稿を測った調査（リール10本・カルーセル3本の実測と、35アカウントの手本の比較）を受けて、作り方の向きを変えた。動きと効果を増やす作りから、「実物・貼り付いた大きな文字・価格・頼み方」で見せる作りへ。

- **投稿の目的を「見積もりのDM」に絞った。** どの案も、最初の画面で「誰向け・何が・いくら・どう頼むか」が分かるようにする。3案とも、価格か頼み方と、行動の案内を同じ投稿に入れる。
- **型カードを、主力5つ（A 日付入り価格／B 価格表／C 注文の手順／D 単品と価格／E 梱包と実績）と補助6つに組み直した。** 毎日の3案は主力から選び、1つ以上はAかBにする。補助は1日1案まで。
- **同じ型を続けて使ってよい。**「同じ型を2日続けない・14日あける」をやめた。変えるのは商品と数字。同じ商品・同じ数字・同じ型は14日以内に2回出さない。
- **リールは、文字を止めて、金額だけを動かす。** 上の文字は0秒から最後まで固定。金額だけ叩き込みで1回。主力の型では、画面の揺れ・フラッシュ・細かいカットを使わない。行動の案内は最後の2秒に、画面でいちばん大きい文字で出す。「技術を全て使う」「静止時間を作らない」の決まりは外した。
- **価格表は、文字だけの表にしない。** 商品の画像を並べ、その真上か真横に金額を置く。
- **自分の見積もり価格を出せるようにした**（`client.json` の `price_display`）。`quote` なら、今日の国内の価格に `quote_markup_percent`（既定10）％を乗せた額を、日付を付けて円とドルで出す。`market`（書いていないときもこちら）は今までどおり、市場の相場だけを出す。前の版のまま使っている相手は、欄を足さなければ今までと同じ。
- **合言葉を1つに固定した**（`client.json` の `contact.keyword`、空なら `PRICE LIST`）。商品ごとに変えない。プロフィールにも同じ頼み方を書いてもらう（人の作業。START_HERE.md）。
- **実写の置き場を足した**（`client.json` の `footage_folder`）。あれば先に使う。無ければ実写なしで作り、型Eは作らない。
- **表の「投稿」タブに「買う言葉のコメント」の列を足した。** `Price?` `Still available?` `DM sent` などが入ったコメントを数える。「相談（DM）」は、合言葉と商品名が入ったDMで数える。数字がたまったら、反応のあった型を多く選ぶ。前の版の表には、AIが右端に列を足す。
- 参考帳に足す手本は、買う言葉のコメントが付いた投稿を、いいねが少なくても足す。
- 検品を16項目にした（最初の画面／価格と行動がセット／文字だけになっていない／重複していない、を追加）。
- 在庫の言い切りをしない決まりは変えていない。価格を出しても、`in stock` `available now` `1 only` は使わない。

リールの秒数（1つ目の金額は6秒まで、尺15〜22秒など）は、同業者のリール3本を測った初期値。自分の投稿の数字で直していく。

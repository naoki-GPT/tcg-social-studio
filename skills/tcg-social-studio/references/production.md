# 作り方（画像・カルーセル・リール）

参考を[測って](reproduction.md)から作る。見た目と動きは[型カード](types.md)で決める。編集元はHTML。完成物は制作フォルダへ、直すたびに v2、v3 と名前を上げて保存する（上書きしない）。

## 共通

- 商品の原画像は、番号・版・状態を確かめたものを使う。商品を描き直して番号や絵柄を変えない。背景・飾りは生成でき、文字・商品・数字は確かめた素材で重ねる。
- 書体は実ファイルを `@font-face` で読み込む。同梱は `fonts/Anton-Regular.ttf`（太い縦長ゴシック）と `fonts/ShipporiMincho-Bold.ttf`（明朝）。既定の書体（Arial等）で済ませない。参考の書体が特定できないときは近い書体で質感を寄せ、表の「気になる点」に書く。
- 画像はPC上に保存したものを使う。HTMLから外のアドレスを直接読まない（撮影時は外への通信を止めている）。
- 最初の画面（画像の1枚目、動画の0秒）で、「誰向け・何が・いくら・どう頼むか」が分かるようにする。上に、誰向けの何の投稿かを1行で置く。
- 締めのアカウント名は `client.json` の `closing` を使う。行動の案内は `contact.keyword` の合言葉で書く。
- 価格の出し方は `client.json` の `price_display` で決まる（[文章](copy.md)の「価格の出し方」）。価格を見せる案には、いつの価格かを画面に入れる。
- 他社の店名・在庫・発送日・実績は、自社の内容に置き換える。確かめていないものは載せない。
- 画面に出した文字は、全部を `03_文章.md` の「画面の文字」に書き写す（[文章](copy.md)）。

## 画像・カルーセル

- 主力の型は、[型カード](types.md)の構成で作る。参考からは、何をどの順で見せているかと、文字の内容を借りる。補助の型は、参考と同じ枚数・同じ順番が既定。
- **文字だけのページを作らない。** 価格表は、商品の画像を並べ、その真上か真横に金額を置く。黒い背景に商品名と金額の行を並べただけの表にしない。
- カルーセルの行動の案内は、最後のページと、本文の1行目の両方に書く。
- 各ページを、HTMLの中の `.slide` 要素1つとして作る（既定 1080×1350。参考の比率が違えばそれに合わせる）。画像1枚の案は `.slide` が1つ。
- 商品の数が参考より少ないときは、元の配置枠いっぱいに拡大し、左右の余白と間隔を均等にする。

```powershell
node scripts/shoot_slides.mjs <制作フォルダ>/index.html --out <制作フォルダ>/slides_v1 --width 1080 --height 1350
```

画像が読み込めていない、書体が当たっていない、`.slide` が無い、大きさが違う、のどれかで止まる。

## リール（動画）は、文字を止めて、金額だけを動かす

反応が出ている同業者のリールは、動きの多さで見せていない。実物と、貼り付いた大きな文字と、価格と、頼み方で見せている。効果を足すほど良くなる、という作り方をしない。見た目の決めは[型カード](types.md)の「どの型でも同じ決め」。

- **固定の文字**：誰向けの何の投稿かを、上に1行、0秒から最後まで出したままにする。価格を出す案は、日付も1.5秒までに出して最後まで残す。途中で消さない、動かさない。
- **動かすのは金額だけ**：金額は、その場面の開始から1秒以内に、叩き込み（拡大→等倍＋少し行き過ぎて戻る）で1回だけ出す。出た後は止めて読ませる。商品名や説明の文字は、出てから動かさない。
- **使わない効果**：主力の型では、画面の揺れ、白いフラッシュ、0.5秒前後の細かいカットを使わない。補助の型でも、1本に1回までにする。
- **カット割**：1つの場面で言うことは1つ。1商品に4〜5秒を使い、読み終わる前に切り替えない。切り替えはハードカットか、横へ送るスライド。参考の動画を測るときは、カットの速さではなく、何を何秒見せているかを測る。
- **最初の3秒**：ロゴだけの画面、店の自己紹介、挨拶を入れない。0秒の時点で、上の固定の文字と商品が見えている。
- **締め**：最後の2秒に、画面でいちばん大きい文字で行動を出す（`DM "PRICE LIST"`）。その下に小さく、送ってもらうもの。締めの前に、金額や商品が残ったままでよい。
- **商品の見せ方**：「商品が画面いっぱい、文字は重ね」。1商品の場面は幅の70%以上、単品の型は85%以上。余白に文字を置く構図にしない。
- **視認性**：文字は、背景の一番ごちゃついた箇所でも一目で読めること。商品の絵の上に重ねる文字は、極太の書体（Anton等）を既定とし、白＋太い黒縁取り＋影＋必要なら暗い下敷きを併用、不透明度は1.0にする。細いセリフ体の重ねは、下敷きを足しても読めない。
- **フォント**：金額と見出しには太い縦長ゴシック（Anton等）、落ち着いた行には明朝を、実ファイルを `@font-face` で読み込んで使う。撮影時にフォントが実際に当たっているか確認する（`window.fontCheck`）。
- **動きの質**：動かすものには必ずイージングを付け、直線的な動きにしない。商品の画像は、ごくゆっくりした寄り（`Parts.kenBurns`）を付けてよい。止まった絵に見せないための動きは、これだけにする。
- **効果音**：同梱の `se-pack/` を使う（`manifest.json` に用途 `use_when` と音量 `default_gain_db` がある）。鳴らすのは、金額が出る瞬間と締めだけ。切り替えのたびに鳴らさない。無音では出さない。自作の合成音は使わない。BGMは使える音源があるときだけ入れ、無いときは表の「気になる点」に「BGMなし」と書く。
- **実写の映像**：`client.json` の `footage_folder` に映像や写真があれば、背景に敷くか、そのまま見せる（[素材を取ってくる](assets.md)）。無ければ、商品の原画像で作る。カード画像から作る動画は、実写の量感や信用には届かない。この差は表の「気になる点」に書く。

### 動きは部品を組み合わせて作る

`templates/parts/parts.js` に、動きの部品が入っている。部品は色や配置を決めない。動きだけを担当する。HTMLに読み込み、`window.seek(t)` の中から呼ぶ。

| 部品 | 動き |
|---|---|
| `Parts.wipeIn` | 帯・プレートが端から伸びて出る |
| `Parts.slam` | 数字の叩き込み |
| `Parts.popWords` | 語ごとに順番にポップ |
| `Parts.tracking` | 字間が広がる／詰まる |
| `Parts.fadeSlide` | フェードしながら移動 |
| `Parts.shake` | 画面の揺れ（主力の型では使わない） |
| `Parts.flash` | 白いフラッシュ（主力の型では使わない） |
| `Parts.sparkle` | 星のきらめき |
| `Parts.lightSweep` | 光の帯が斜めに横切る |
| `Parts.kenBurns` | ゆっくり寄る・流す |
| `Parts.cut` | 場面のハードカット |
| `Parts.countUp` | 数字が数え上がる |

引数は `parts.js` の各部品の先頭に書いてある。使うときの決まりは3つ。

- `window.seek(t)` の中で、毎回すべての部品を呼ぶ（呼ばれなかった部品は前の状態のまま残る）。
- 1つの要素に動く部品を2つ重ねない。重ねたいときは要素を入れ子にする（外側に `shake`、内側に `slam` など）。
- `Parts.cut` を使う場面の要素には、`display` を直接書かない。`Parts.popWords` に渡す語の要素は、最初に1回 `Parts.splitWords(要素)` で作る。
`templates/parts/demo.html` は部品が動くことの確認用で、見た目の手本ではない。

**完成した動画の見本は、手本にしない。** `templates/reel-example/` は、編集元の書き方（下の3つの約束）と道具の確認のための1例。色・配置・秒数を流用しない。見た目は、参考の実測と型カードから、毎回組み立てる。

### 編集元（index.html）の約束

撮影の道具は、ページに次の3つがあることを前提にしている。

| 用意するもの | 役割 |
|---|---|
| `window.seek(t)` | 時刻 t（秒）を受けて、その瞬間の画面を決める関数。同じ t なら必ず同じ画面になること。 |
| `window.ready` | 書体と画像の読み込みが済んだら完了する約束（Promise）。 |
| `window.fontCheck` | 使う書体ごとに、実際に当たっているかを true / false で持つ。1つでも false なら撮影は止まる。 |

### 書き出し

```powershell
# 1. コマを撮る（尺は今回の動画に合わせる）
node scripts/capture_frames.mjs <制作フォルダ>/index.html --out <制作フォルダ>/frames_v1 --duration <秒> --fps 30

# 2. 効果音を並べる（時刻は cues.json に書く）
python scripts/mix_audio.py <制作フォルダ>/cues.json --out <制作フォルダ>/audio_v1.wav

# 3. MP4にして、実物を調べる
node scripts/finish_video.mjs --frames <制作フォルダ>/frames_v1 --audio <制作フォルダ>/audio_v1.wav --out <制作フォルダ>/reel_v1.mp4 --checks <制作フォルダ>/checks/v1 --times <見たい時刻をカンマ区切り>
```

`cues.json` の形：

```json
{
  "duration": 13.0,
  "cues": [
    {"file": "whip_01.mp3", "t": 0.30, "trim": 1.3},
    {"file": "coin_01.mp3", "t": 2.23, "gain_db": -10}
  ]
}
```

- `t` は鳴らす時刻（秒）。画面で動きが起きる時刻に合わせる。`gain_db` を省くと `manifest.json` の音量になる。`trim` は長い音を途中で切る秒数。
- `mix_audio.py` が「credit required」と出したら、本文の最後に OtoLogic のクレジットを入れる（[文章](copy.md)）。
- 仕上がりは H.264 / yuv420p / AAC、1080×1920、30fps。`finish_video.mjs` は音声が入っていないMP4を不合格にする。
- `--times` には、0秒、金額が出る時刻、最後の2秒の始まりを必ず入れる。そのコマを開いて目で確かめる（[検品](check.md)）。

## 表に貼る「見た目」の画像を作る

完成物ごとに1枚作る。人が表で、アドレスを開かずに中身を見分けるための画像。

```powershell
# リール：等間隔の3コマを横に並べる
python scripts/make_preview.py <制作フォルダ>/reel_v1.mp4 --out <制作フォルダ>/preview_v1.jpg

# カルーセル：先頭3枚を横に並べる（画像1枚の案は、その1枚）
python scripts/make_preview.py <制作フォルダ>/slides_v1 --out <制作フォルダ>/preview_v1.jpg
```

できた画像を共有フォルダに置き、表の「見た目」に出す（[表の書き方](sheet.md)）。

## 静止画の参考を動画にしたとき

静止画の参考に動きを足したものは「動画化した案」。表の「気になる点」に書く。

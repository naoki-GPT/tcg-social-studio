# 検品

書き出せた、動画が再生できた、文字が切れていない、だけでは完成ではない。3案それぞれについて次の11項目を確かめ、1つでも足りなければその案を直す。直せなければ、商品か参考を替えて作り直す。人に判定を頼まない。

結果は制作フォルダの `checks/検品.md` に、項目ごとに「何を開いて、何を見て、何を直したか」を1〜2行で残す。印を付けるだけで済ませない。

## 作る前（工程2〜3の終わりに）

1. **商品**：海外で直近30日に同じ条件で3件以上売れた記録があり、国内と海外の価格を今日読んでいる。
2. **買い手の得**：なぜ今これを見せるのかが具体的。価格差を得にするなら、同じ条件どうしを比べている。
3. **行動**：画面・本文・実際の受け口がつながっている。本文に「何を送るか／どこを開くか」がある。
4. **参考**：全枚／全編が保存され、測ってある。

足りない案は、商品か参考を替える。弱さをデザインや強い言葉で隠さない。

## 作った後（工程6）

5. **全対応**：そのまま再現する参考なら、参考の全ページ・全カット・全テロップ・全効果に、完成物の側の対応がある。作り替えた参考なら、構成とテンポが合っている。変えた点は理由を書く。
6. **見た目**：全ページを参考と同じ大きさで並べ、配置・文字・配色・商品の面積・背景まで見る。動画は同じ時刻で全編を比べ、切り替えの前後1コマ、動きの始まり・途中・終わりを開く。冒頭だけで合格にしない。

```powershell
python scripts/compare_reference.py slides --ref <制作フォルダ>/reference --ours <制作フォルダ>/slides_v1 --out <制作フォルダ>/checks/compare
python scripts/compare_reference.py video --ref <参考.mp4> --ours <制作フォルダ>/reel_v1.mp4 --out <制作フォルダ>/checks/compare
```

   比較画像を作っただけでは合格ではない。開いて見る。

7. **内容**：商品・価格・日付・数量・単位・合言葉・行動の案内が、画面の文字・本文・日本語訳で一致している。表に書く「画面の文字」が、完成物に出ている文字と1字も違わない。確かめていない言い切りが入っていない。
8. **技術**：解像度・比率・尺・画像の読み込み・終わり方・音声の有無・文字切れ。`finish_video.mjs` の `checks/video.json` を読み、抜いたコマを開く。実際のMP4で止まっている動きは「未実装」。

9. **価格の向き**：国内と海外の価格を並べるときは、国内の価格を今日の為替で相手の通貨に直し、**国内のほうが安い**ことを確かめる。国内のほうが高い、またはほぼ同じ商品は、価格を比べる見せ方をやめるか、商品を替える。計算は `01_調査.md` に残す（例：¥11,900 ÷ 155 = $76.77 ＞ 海外 $74.45 → 不合格）。
10. **在庫の言い切り**：`in stock`、`available now`、`ready to ship`、`ALSO IN STOCK` など、在庫がある・すぐ送れると読める言葉が、画面にも本文にも無い。問い合わせを促す言い方（`DM for today's price` など）にする。
11. **余白と重なり**：全ページ・全場面を開いて見る。
    - 文字や画像が、ほかの文字・画像・表の行に重なっていない。店名やアカウント名の帯が、中身の上に乗っていない。
    - ページや画面の半分以上が空いていない。空いていたら、商品を大きくするか、中身を上下に配り直す。文字だけで中身が3行ほどのページは、前後のページにまとめる。
    - リールは、縦長の画面の上から下までを使っている。上半分だけに寄っていない。
    - 商品画像に、棚・袋・手・値札・他人の背景が写り込んでいない。粗い画像を引き伸ばしていない。

### リールで必ず開くコマ

- 一番ごちゃついた背景に文字が重なる時刻（読めるか）。
- フラッシュ・きらめき・叩き込みなど、一瞬の効果が出る時刻（出ているか）。
- 価格など核心の情報が出る場面の、開始から1秒の時刻（出ているか）。
- 最後の締め（`closing` のとおりか）。

## 3案を並べて確かめる

- 3案が、商品も型カードも別になっている。色だけ違う同じ作りになっていない。
- きのうの3案と、同じ型が重なっていない。
- 「見た目」の画像を3枚並べて、一目で違う投稿に見える。
- **3案の背景の色・文字の色・書体の組み合わせが、3つとも違う。** 2案以上が同じ組み合わせ（例：どれも紺地に金の文字）なら不合格。それぞれの参考の原本と商品の色に合わせて作り直す。
- きのうの3案とも、同じ組み合わせが続いていない。

## 不合格の書き方

理由は具体的に書く。「弱い」ではなく、「本文にDMで送る内容がない」「英語版の売れた記録しかなく、日本語版を確かめていない」「元9枚のうち8枚目に対応がない」「0.80秒の字幕が1.20秒にずれた」のように書く。

## 表へ渡すこと

直しきれずに残った差（近い書体での代用、聞いて確かめられなかった音、カード画像では届かない実写の反射など）は、表の「気になる点」に短く書く。検品で通ったことを、売れる・集客できることの証明として書かない。

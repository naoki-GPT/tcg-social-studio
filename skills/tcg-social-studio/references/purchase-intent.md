# 参考の全文から、買う理由と行動を作る

v2.0 / 2026-11-12。デザインが似ていても何の提案で何をすればよいか伝わらなければ不合格。

## 全文の分析表

画像は全ページ、動画は全編の画面文字と音声、投稿本文、誘導先を読む。OCR／音声認識は下書き。数字・否定・日時・条件・商品名を原画／音声で直し、聞けないところは未確認とする。

| 項目 | 一枚・一時刻ごとに記録する中身 |
|---|---|
| 原文と場所 | 見出し・小文字・発話・本文、ページ番号／時刻 |
| 意味 | 日本語。主語・比較軸・否定を保持 |
| 欲求／問題 | 安く仕入れたい、好きな種類だけ欲しい、納期を合わせたい等 |
| 利益と根拠 | 何が得か。価格差・内訳・実演・期限のどれが支えるか |
| 不安への答え | 数量・言語・状態・手間・納期の懸念をどこで解消するか |

| 判断の変化 | 見る前の迷い→分かること→次を読む理由 |
| 自社への変更 | 残す構造、替える事実、裏付けのない条件 |

参考の主張と市場の事実は別。分析レポートでは実画像・短い原文・分析を近接配置する。全文控えは内部調査用に分ける。

例えば同一市場の時点比較から言語別価格差は証明できない。元投稿が「高値で急がなくてもよい」と言う場合、「今すぐ仕入れ」に変えるには別の根拠が必要。元がコメント誘導ならDM追加は自社版の変更として扱う。

## 提案の一文

「［客］へ、［需要のある特定商品］を、［今の確認済み利益］を理由に提案し、［具体的行動］をしてもらう。」

これを埋める前に見出しを作らない。商品が何でも成立する賛辞や「Which one?」だけでは販売訴求に不足。問いを使うなら投稿内で数字・答えを回収する。

画面上部には具体的利益、すぐ識別できる商品、読める比較ラベルと数字を置く。参考から見出しを変える場合は意図した差に記録する。本文は証拠→客の利益→行動へつなぐ。

- **言語別**：同じ絵柄・各番号→日本語版の対象国需要→両版の同条件価格→買い手に意味のある差→日本語版の価格・在庫相談。差が小さければこの企画を捨てる。
- **値下がり**：同一商品・状態・市場・価格種別の2時点→下げ幅→前回見送った客の利益→現在条件の確認。2点から途中の折れ線を創作しない。
- **選べる単品**：不要なカードも買う負担→好きな1枚だけ選べる提供条件→対象と買い方。単品対応が未確認なら約束しない。
- **B2B補充**：用途と需要→レアリティ・数量・内訳→条件を送って相談。競合の大量在庫・VIP制度は自社へ持ち込まない。
- **予約・発送**：販売企画の時期→自社で確認済みの受付・発送条件→商品／数量を添えた相談。競合の最速・即日をコピーしない。

## 本文に実際の行動文を入れる

DM例（対応可能な業務が確認できている場合）：
“DM us the card name, quantity and destination country to check current price and availability.”
「現在の価格と在庫の確認は、カード名・希望枚数・配送国を添えてDMしてください。」

リンク誘導は、実在の商品ページ名とそこで何を確認してほしいかを書く。プロフィールから実際にそのページへ行けるか確認する。仮URLや角括弧は完成物に残さない。

主要行動は一つ。購入・DM・コメント・保存を同列に並べて迷わせない。画像内だけ、ハッシュタグだけのCTAは本文の代用ではない。CTAを強くしても、その前に利益・根拠がなければ不合格。

## 原稿の判定

商品と比較軸が具体的か。数字と根拠は一致するか。「人気」「今がチャンス」「あなただけ」に各々証拠があるか。買い手に意味のある差か。次の操作と送る内容が分かるか。画面→本文→誘導先で提案が続くか。該当原文とともに確認を記録する。

英日で約束・確度を変えない。内部注釈を本文へ並べず、比較ラベルで外部相場と自社売価を正しく区別する。

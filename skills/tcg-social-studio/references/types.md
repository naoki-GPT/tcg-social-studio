# 型カード（見た目と動きの決め）

型が違えば、背景・書体・文字の出し方・切り替え方・音も変える。同じ作りの色違いを「別の投稿」にしない。

**使い方**

- 「カード画像と文字だけで作れる」参考をそのまま再現するとき：参考を測った値が優先。カードは、参考から読み取れない所を決めるときに使う。
- 「実物の映像が要る」参考を作り替えるとき：構成とテンポは参考から、見た目と動きはこのカードから決める。
- 色は例。その日の商品の色（カードの絵、BOXの箱）に合わせて変える。**同じ型カードを2日続けて使わない。** その日の3案は、3つとも違うカードにする。
- 最後の締め（`client.json` の `closing`）だけは、どのカードでも同じ出し方にする。

参考帳の「型」と、使うカードの対応：

| 参考帳の型 | 使うカード |
|---|---|
| 価格表、言語別の価格比べ、卸価格表の告知 | 1 価格表 |
| 値動きの速報、値動きのまとめ、相場の問いかけ＋グラフ | 2 値動き |
| 予約・先行の告知、発売・入荷の告知、予約＋中身の紹介、新商品の紹介 | 3 告知 |
| ラインナップ（1枚1ページ／4枚まとめ）、商品ビジュアル1枚、欲しい1枚だけ買える | 4 ラインナップ |
| 1枚ずつ紹介 | 5 1枚ずつ紹介（リール） |
| 大量の実物を見せる | 6 たくさん並べる（リール） |
| 注意喚起＋セット案、売り先ごとの価格比べ、注文手順の紹介 | 7 強い呼びかけ |

新しい型が参考帳に増えたら、いちばん近いカードを使う。

---

## 1 価格表

落ち着いていて、数字が読みやすい型。

| 項目 | 決め |
|---|---|
| 背景 | 濃い単色（紺・深緑・えんじ など）に、細い金や白の枠と罫線。飾りは少なく |
| 書体 | 見出しは明朝（Shippori Mincho）で字間を広く。数字は極太（Anton） |
| 配置 | 上に見出し、その下に商品の小さな画像と名前、右に価格。1行1商品 |
| 文字の出し方（リール） | 見出しは字間が詰まりながら出る。行は上から1行ずつ、帯のワイプで出て、価格は少し遅れて叩き込む |
| 切り替え | 1画面のまま行が増えていく。最後に行動の帯 |
| 音 | 行が出るたびに短い音、価格に硬貨の音、最後にレジの音 |
| 尺 | 4商品で12〜13秒 |
| 向く商品 | 複数のシングル、複数のBOX、日本語版と英語版 |

## 2 値動き

「動いた」ことを一目で伝える、強い型。

| 項目 | 決め |
|---|---|
| 背景 | 黒に近い色。上がったら緑、下がったら赤を1色だけ効かせる |
| 書体 | 極太ゴシック（Anton）を大きく。説明は小さい白 |
| 配置 | 1枚目：商品と大きな％。2枚目：2時点の価格を結ぶ線と数字。3枚目：理由か問いかけ |
| 文字の出し方（リール） | ％は叩き込み（拡大から等倍、少し行き過ぎて戻る）。線は左から伸びる。数字は数え上がる |
| 切り替え | ハードカット。山場で白いフラッシュと短い揺れ |
| 音 | 叩き込みに重い音、切り替えに風切り音 |
| 尺 | 8〜12秒 |
| 向く商品 | 価格が動いたBOX・PSA・シングル |

グラフは、確かめた2つの時点だけを結ぶ。間の折れ線を作らない。

## 3 告知

商品そのものを大きく見せる、明るい型。

| 項目 | 決め |
|---|---|
| 背景 | 明るい空・光・雲など、商品の箱の色に合わせた生成背景 |
| 書体 | 上下の帯に極太の見出し。細かい条件は明朝か細いゴシック |
| 配置 | 中央に商品を大きく1つ（画面の幅の70%以上）。上の帯に何の告知か、下の帯に条件を3行まで |
| 文字の出し方（リール） | 上の帯がワイプで入り、商品がゆっくり寄る。条件は1行ずつ下から |
| 切り替え | 1画面。カルーセルなら2枚目に中身や内訳 |
| 音 | 帯に短い音、商品に光の音 |
| 尺 | 6〜10秒 |
| 向く商品 | 新しいBOX、予約の商品、セット |

発売日・数量・最速などは、確かめたものだけ書く。確かめていなければ「相談を受け付けています」にする。

## 4 ラインナップ

カードの絵の強さで見せる、文字の少ない型。

| 項目 | 決め |
|---|---|
| 背景 | そのカード自身を大きくぼかしたもの。または黒 |
| 書体 | 文字は最小限。短いひと言だけを、白の極太に黒の縁取りで |
| 配置 | カードを画面いっぱいに（幅の85%以上）。1ページ1枚、または黒地に4枚 |
| 文字の出し方（リール） | カードがゆっくり寄る。ひと言は語ごとにポップ |
| 切り替え | カルーセルは1枚1ページで6〜9枚。4枚まとめは1枚絵 |
| 音 | 切り替えに軽い音、ホロのきらめきに高い音 |
| 尺 | 1枚あたり約1.5〜2秒 |
| 向く商品 | AR・SAR・人気の絵柄のシングル |

## 5 1枚ずつ紹介（リール）

実物を手に持って1枚ずつ見せる参考を、カード画像で作り替える型。

| 項目 | 決め |
|---|---|
| 背景 | 黒。カードのまわりに薄い光 |
| 書体 | 情報のテロップは、白の太い斜体ぎみのゴシックに黒の縁取り |
| 配置 | カードを画面いっぱいに。下3分の1に「名前と番号／セット名／絵師」の3行 |
| 文字の出し方 | カードが切り替わると同時に、3行が下から短く入る |
| 動き | 1枚ごとに、少し傾いた位置から正面へ戻る動き＋光の帯が斜めに横切る。止まった絵にしない |
| 切り替え | ハードカット。約2秒ごと。最初の1枚で引きつけ、6〜8枚見せ、最後に最初の1枚へ戻る |
| 音 | 切り替えごとに短い音、光の帯にきらめきの音 |
| 尺 | 14〜18秒 |
| 向く商品 | 絵柄の強いシングル、同じテーマでそろうカード |

## 6 たくさん並べる（リール）

机いっぱいの実物を見せる参考を、カード画像で作り替える型。静かな型。

| 項目 | 決め |
|---|---|
| 背景 | 黒か濃い色の布のような単色 |
| 書体 | 細めの明朝を小さく、左下に。文字は控えめ |
| 配置 | カード画像を格子や扇の形に12枚以上並べ、画面からはみ出す大きさで |
| 動き | 全体を斜めにゆっくり流す。場面ごとに流す向きを変える |
| 切り替え | 3〜4場面をハードカット。最後は単色の画面に店の名前だけ |
| 音 | 落ち着いたBGMがあれば入れる。切り替えに小さな音 |
| 尺 | 12〜20秒 |
| 向く商品 | ARバルク、ヴィンテージ、同じ弾のまとめ |

読みにくくならないよう、文字の下には暗い下敷きを入れる。

## 7 強い呼びかけ

注意や比べを、はっきり言う型。

| 項目 | 決め |
|---|---|
| 背景 | 黄と黒、赤と白など、強い2色 |
| 書体 | 極太ゴシックを大きく。大事な語だけ色を変える |
| 配置 | 上に強い見出し、中央に商品や比べる数字、下に行動の帯 |
| 文字の出し方（リール） | 見出しは叩き込み、数字は左右から入って並ぶ |
| 切り替え | カルーセルは、呼びかけ→案1→案2→注文の方法、の順 |
| 音 | 見出しに重い音、数字に短い音 |
| 尺 | 8〜12秒 |
| 向く商品 | セット売り、店・配信者向けのまとめ、手順の説明 |

他社についての注意や悪い話は、自分で確かめたことだけ書く。確かめていなければ、この型でも「比べ」か「手順」に使う。

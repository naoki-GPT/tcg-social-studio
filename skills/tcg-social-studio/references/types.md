# 型カード（何を見せ、どう見せるかの決め）

投稿の目的は、見積もりのDMをもらうこと。再生数やいいねの多さではない。そのために、どの型でも**最初の画面で「誰向け・何が・いくら・どう頼むか」が分かる**ように作る。

型は「主力」と「補助」に分かれる。

- **主力の型（A〜E）**：日本から海外へ売る同業者が何度も繰り返し、コメントに `Price?` `DM sent` などの買う言葉が付いていた型。毎日のネタは、ここから選ぶ。
- **補助の型（1〜7）**：商品の魅力や値動きを見せる型。1日に1案まで。使うときも、下の「どの型でも同じ決め」を守る。

**同じ型を続けて使ってよい。** 効く型は繰り返す。変えるのは商品と数字。同じ商品・同じ数字の投稿を2回出さない。

主力の型の秒数や大きさは、同業者の投稿を測った初期値。表の「聞かれた商品」タブに行がたまったら、聞かれた商品を出したときの形に寄せて直す。

## どの型でも同じ決め

| 決め | 内容 |
|---|---|
| 上の固定の文字 | 画面の上に、誰向けの何の投稿かを1行で出す。**誰向けかは、ネタで決めた1つを言い切る**（例：`For new resellers — Japanese Pokémon cards from Japan`、`For shops & resellers — Japanese Pokémon cards from Japan`、`For collectors — Japanese Pokémon cards from Japan`）。`Japanese Pokémon cards — direct from Japan` のように、誰向けかが無い1行にしない。ワンピースカードの案は `Pokémon` を `One Piece` に、両方を並べる案は `Japanese TCG` にする。リールは**0秒から最後まで出したまま**にする。途中で消さない、動かさない。 |
| 日付 | 価格を出す案は、`Prices as of Nov 19` のように日付を出す。リールは1.5秒までに出し、最後まで残す。 |
| 金額 | 画面でいちばん大きい文字にする。円とドルを並べる（例：`¥17,200 ($111)`）。価格の決め方は[文章](copy.md)の「価格の出し方」。 |
| 動かすもの | 動かして目立たせるのは金額だけ。出る瞬間に1回だけ叩き込み、その後は止めて読ませる。上の固定の文字、商品名、日付は動かさない。 |
| 使わない効果 | 画面の揺れ、白いフラッシュ、0.5秒前後の細かいカット。主力の型では使わない。 |
| 商品 | 商品の画像を大きく（画面の幅の70%以上、複数並べるときは1つが幅の20%以上）。文字だけの画面を作らない。 |
| 締め | リールは**最後の2秒**に、画面でいちばん大きい文字で行動を出す（例：`DM "PRICE LIST"`）。その下に小さく、送ってもらうもの（`item + quantity + country`）。アカウント名は `client.json` の `closing`。 |
| 店の自己紹介 | 最初の3秒に、ロゴだけの画面や挨拶を入れない。 |
| 在庫の言い方 | `IN STOCK` `Available now` `1 only` は使わない。手元に無い商品を、ある・すぐ送れると読める言い方にしない（[検品](check.md)の10）。 |

参考帳の「型」と、使うカードの対応：

| 参考帳の型 | 使うカード |
|---|---|
| 価格の速報、日付入りの価格、セール | A 日付入り価格 |
| 価格表、卸価格表の告知、言語別の価格比べ、売り先ごとの価格比べ | B 価格表 |
| 注文手順の紹介 | C 注文の手順 |
| 商品ビジュアル1枚、欲しい1枚だけ買える、新商品の紹介 | D 単品と価格 |
| 梱包・発送の様子、再注文の実績、お客さんのレビュー | E 梱包と実績（実写かレビューの画面があるときだけ） |
| 値動きの速報、値動きのまとめ、相場の問いかけ＋グラフ | 補助1 値動き |
| 予約・先行の告知、発売・入荷の告知、予約＋中身の紹介 | 補助2 告知 |
| ラインナップ（1枚1ページ／4枚まとめ） | 補助3 ラインナップ |
| 1枚ずつ紹介 | 補助4 1枚ずつ紹介（リール） |
| 大量の実物を見せる | 補助5 たくさん並べる（リール） |
| 注意喚起＋セット案 | 補助6 強い呼びかけ |
| 業者の悩みを見出しにした投稿 | 補助7 悩みから入る |

新しい型が参考帳に増えたら、いちばん近いカードを使う。

# 主力の型

## A 日付入り価格（リール・画像）

「今日、この商品がいくらか」を見せる型。

| 項目 | 決め |
|---|---|
| 構成 | 1画面に1商品。商品は3〜4点。最後に締め |
| 最初の画面 | 0秒から、上の固定の文字と1つ目の商品が見えている。1.5秒までに日付 |
| 価格の出し方 | 各場面の開始から1秒以内に、金額を叩き込みで出す。**1つ目の金額は6秒までに出す** |
| 1商品の長さ | 4〜5秒。金額が出た後は止めて読ませる |
| 切り替え | ハードカットか、横へ送るスライド |
| 背景 | 濃い単色か、その商品を大きくぼかしたもの。実写の映像があれば（`client.json` の `footage_folder`）それを下に敷く |
| 書体 | 金額は極太ゴシック（Anton）。商品名は白の太い文字に黒の縁取り |
| 音 | 金額が出る瞬間と締めにだけ短い音 |
| 尺 | 15〜22秒 |
| 画像1枚で作るとき | 商品を2〜4点並べ、それぞれの真上に金額。上に固定の文字と日付、下に行動の1行 |
| 向く商品 | BOX、PSA、人気のシングル |

## B 価格表（カルーセル・画像）

商品の実物を並べ、その真上に価格を置く型。**文字だけの表にしない**（黒い背景に商品名と金額の行を並べただけの表は、見てもらえない）。

| 項目 | 決め |
|---|---|
| 1ページ目 | 商品の画像を格子に並べる（BOXなら2段×4列で8点まで、カードなら2×2か3×2）。**それぞれの商品の真上か真横に金額**。上に `PRICE LIST — Nov 19` と日付 |
| 2ページ目から | 商品を1〜2点ずつ大きく。商品名、番号、版、状態（シュリンクの有無など）、金額 |
| 最後のページ | 頼み方を1つだけ（`DM "PRICE LIST" with item + quantity + country`）。同じ1行を本文の1行目にも書く |
| 金額の文字 | 白の極太に黒の縁取り。商品の画像と同じくらい目立つ大きさ |
| 背景 | 明るい単色か、濃い単色。商品の箱の色がはっきり見える色にする |
| 枚数 | 4〜10枚 |
| 向く商品 | 複数のBOX、複数のシングル、日本語版と英語版 |

## C 注文の手順（リール・カルーセル）

「どう頼めばいいか」を4つの手順で見せる型。買い手のコメントは、価格だけでなく「買い方・送料・まだ頼めるか」にも集まる。

| 項目 | 決め |
|---|---|
| 最初の画面 | 上に `HOW TO ORDER FROM JAPAN` など、何の案内かが分かる見出しと、今日頼める商品の画像 |
| 手順 | 画面に4つ。`1. DM with item + quantity + country` `2. I send today's price + shipping total` `3. Pay by Wise / PayPal` `4. Packed carefully, shipped from Japan`。支払いと発送の方法は、その相手が実際に使うものだけ書く |
| リール | 1手順に1場面、各3〜4秒。手順の番号を大きく。商品の画像は場面ごとに替える |
| カルーセル | 1ページ目に見出しと商品、2〜5ページ目に手順を1つずつ、最後に頼み方 |
| 価格 | 1商品だけ、例として金額を出す（「たとえばこのBOXは今日 ¥○○」）。 |
| 尺 | 16〜20秒 |
| 向く商品 | BOX、セット、店・配信者向けのまとめ |

## D 単品と価格（リール・画像）

1枚、または1BOXだけを大きく見せ、今日の価格と頼み方を添える型。

| 項目 | 決め |
|---|---|
| 最初の画面 | 商品を画面いっぱいに（幅の85%以上）。上に商品名と番号 |
| 価格 | 2秒までに金額を叩き込みで出す |
| 中盤 | 同じ商品を、寄り・全体の2〜3場面で見せる。商品の画像は正規の原画像だけ。状態（NM など）は、実物を確かめていなければ書かない |
| 締め | `DM "PRICE LIST" for today's price & shipping.` |
| 尺 | 8〜12秒 |
| 向く商品 | AR・SAR・PSA 10、人気のBOX |

## E 梱包と実績（実写かレビューの画面があるときだけ）

梱包の手元、発送した箱、お客さんのレビューを見せる型。信用のもとは本物なので、**`client.json` の `footage_folder` に、実写の映像や写真か、お客さんのレビューの画面（届いたあとのDMや感想を保存した画像）があるときだけ作る。** カード画像での作り替えはしない。人・倉庫・箱の山・レビューの文を生成しない。

| 項目 | 決め |
|---|---|
| 構成 | 実写を1本、切らずに見せる。上に固定の文字、途中に数字の一言（例：`First order: 17 boxes → Reorder: 51`）。数字は実際にあったものだけ |
| レビューの画面で作るとき | 画像かカルーセル。レビューの画面を大きく置き（幅の70%以上）、その横か下に、その人が頼んだ商品の画像を添える。レビューの文は、書かれたとおりに見せる。書き足さない、言い換えない。日本語などのレビューは、下に英語の訳を小さく添える。お客さんの名前・アカウント名・顔写真・住所は隠す。上の固定の文字、頼み方、行動の案内は、ほかの型と同じ |
| 締め | 最後の2秒に行動 |
| 尺 | 12〜20秒 |

# 補助の型

商品の魅力や値動きを見せる型と、客の悩みから入る型。1日に1案まで。どの型でも、上の「どの型でも同じ決め」のとおり、価格か頼み方と、行動の案内を必ず入れる。色は例で、その日の商品の色に合わせて変える。

## 補助1 値動き

| 項目 | 決め |
|---|---|
| 背景 | 黒に近い色。上がったら緑、下がったら赤を1色だけ効かせる |
| 書体 | 極太ゴシック（Anton）を大きく。説明は小さい白 |
| 配置 | 1枚目：商品と大きな％。2枚目：2時点の価格を結ぶ線と数字。3枚目：今日の価格と頼み方 |
| 文字の出し方（リール） | ％と金額だけ叩き込み。線は左から伸びる |
| 尺 | 8〜12秒 |
| 向く商品 | 価格が動いたBOX・PSA・シングル |

グラフは、確かめた2つの時点だけを結ぶ。間の折れ線を作らない。グラフだけで終わらせない。最後は今日の価格と頼み方にする。

## 補助2 告知

| 項目 | 決め |
|---|---|
| 背景 | 明るい空・光・雲など、商品の箱の色に合わせた生成背景 |
| 配置 | 中央に商品を大きく1つ（画面の幅の70%以上）。上の帯に何の告知か、下の帯に条件を3行まで |
| 尺 | 6〜10秒 |
| 向く商品 | 新しいBOX、予約の商品、セット |

発売日・数量・最速などは、確かめたものだけ書く。確かめていなければ「相談を受け付けています」にする。

## 補助3 ラインナップ

| 項目 | 決め |
|---|---|
| 背景 | そのカード自身を大きくぼかしたもの。または黒 |
| 配置 | カードを画面いっぱいに（幅の85%以上）。1ページ1枚、または黒地に4枚。カードの下に名前・番号・金額 |
| 枚数・尺 | カルーセルは6〜9枚。リールは1枚あたり約2秒 |
| 向く商品 | AR・SAR・人気の絵柄のシングル |

## 補助4 1枚ずつ紹介（リール）

| 項目 | 決め |
|---|---|
| 背景 | 黒。カードのまわりに薄い光 |
| 配置 | カードを画面いっぱいに。下3分の1に「名前と番号／セット名／金額」の3行 |
| 動き | カードが切り替わるときだけ、少し傾いた位置から正面へ戻る。光の帯が1回横切る |
| 切り替え | ハードカット。約2秒ごと。6〜8枚 |
| 尺 | 14〜18秒 |
| 向く商品 | 絵柄の強いシングル、同じテーマでそろうカード |

## 補助5 たくさん並べる（リール）

| 項目 | 決め |
|---|---|
| 背景 | 黒か濃い色の単色 |
| 配置 | カード画像を格子や扇の形に12枚以上並べ、画面からはみ出す大きさで |
| 動き | 全体を斜めにゆっくり流す。3〜4場面 |
| 尺 | 12〜20秒 |
| 向く商品 | ARバルク、同じ弾のまとめ |

文字の下には暗い下敷きを入れる。枚数やロットの価格を、上の固定の文字の下に出す。

## 補助6 強い呼びかけ

| 項目 | 決め |
|---|---|
| 背景 | 黄と黒、赤と白など、強い2色 |
| 書体 | 極太ゴシックを大きく。大事な語だけ色を変える |
| 配置 | 上に強い見出し、中央に商品や比べる数字、下に行動の帯 |
| 尺 | 8〜12秒 |
| 向く商品 | セット売り、店・配信者向けのまとめ |

他社についての注意や悪い話は、自分で確かめたことだけ書く。

## 補助7 悩みから入る（カルーセル・画像・リール）

買い手の悩みを見出しにし、その解決として商品と頼み方を出す型。誰向けかを言い切りやすい。

| 項目 | 決め |
|---|---|
| 最初の画面 | 上の固定の文字（誰向け）と、悩みを1行で言い切った見出し（例：`Why your bulk lots don't sell.`、`Starting small? You don't need a full case.`）。商品の画像も同じ画面に置く |
| 悩みの元 | 表の「聞かれた商品」タブの、種類が `聞かれた質問` の行。無ければ、買い手がよく気にすること（何がすぐ売れるか、少ない予算で始められるか、送料込みでいくらになるか、本物か・状態はどうか）から、今日の商品に合うものを1つ |
| 構成 | 1：悩みの見出し → 2：そうなる理由を1〜2つ → 3：解決になる商品（種類・数量・内訳）と、価格か頼み方 → 4：行動。カルーセルは4〜6枚。リールは8〜12秒 |
| 理由の書き方 | 今日調べて確かめたことだけ書く（海外で売れた記録、国内の価格、扱える単位など）。確かめていない話を、理由にしない |
| 価格 | 3で、金額か「見積もりを出します」のどちらかを必ず出す。最初の画面に金額が無くてもよい |
| 書かないこと | 利益の額や「もうかる」の約束。関税や税金の率・額の言い切り（国と時期で変わる。「合計を先に返します」と書く）。ほかの売り手を悪く言う話 |
| 向く商品 | まとめ売り、パック、少ない数から頼めるシングル |

# 競合・販売導線・商品を調べる

## 競合調査

入口は商品、対象客、既存の参考URL。直接の販売者、海外店、商品紹介者を分けて選ぶ。全体10〜25候補・直近90日・各20〜30投稿は初回の目安で、15件や30件で固定しない。異なる商品・客・導線を説明できないときは拡張する。追加理由、調査期間、取得日、対象件数、取得上限と未取得を記録する。

公開情報調査はMuse側で利用可能な機能を使い、取得済みデータを保存して再集計・資料修正に再利用する。市場調査は[価格比較手順](price-comparison.md)、参考素材は[受け渡し手順](media-input.md)に従う。ブラウザーUI巡回へ自動で切り替えない。取得不能の項目は不足として残し、未取得を取得済みにしない。

取得方法、元URL、取得時刻、対象範囲、確認できた本文・画像・数値を記録する。作成者だけが使える収集サービスや認証に依存した手順を配布先へ要求しない。

### 比較する条件

- アカウント内の「対象アカウント＋投稿ID」で重複を除く。全体の異なる投稿数は別途投稿IDで数える。
- 同じ形式・指標で比較。再生数と視聴数、いいね、コメントは足し合わせない。欠損・非表示・負の代替値は不明。実測0は0。
- 代表例は高反応と通常例を両方確認。最大値だけでなく中央値、母数、対象期間、公開後の経過日数を残す。固定・PR・抽選を別扱いにする。
- 現在のフォロワー数1回で成長率を出さない。反応を売上・保存数・視聴完了率へ換算しない。工夫と反応の因果が不明なら「観察された工夫／こちらで試す案」。
- `scripts/analyze_posts.py` は [正規化したJSON](data-format.md) から比較表を作る。元サービスの項目を自動で意味変換しない。取得・観察・候補選びはAIが別途行う。

### 投稿ごとの観察

URL／投稿日／取得日／形式／数値／確認範囲／冒頭の画と訴求／商品が占める大きさ／切替／字幕量／最後の案内／顔・声への依存／こちらで採用する部分。

実際に閲覧できた画を保存し、生成した画像を参考の実画面として使わない。静止画から動きを設計した場合は、元の観察と自作の秒割りを分ける。参考本文は必要部分だけ短く引用し、残りは要約する。

### 販売導線

プロフィール → 直接ストア／リンク集 → 商品詳細／問い合わせ → 注文と支払い方法 → 発送・再購入の案内。

各段階のURL、スクリーンショット、売っている商品、価格の表示方法、最低数量、連絡手段、送料・納期・返品等の見える条件を記録する。リンクだけ確認、本文確認、画面操作確認を分ける。注文・DM・フォーム送信は行わない。連絡先はユーザーの実際のものへ置き換える。

### 初見の人向けの結論

「何のために調べたか」→「分かったこと」→「どの投稿・売買ページで確認したか」→「どこを真似するか」。1例につき実画像＋短い説明＋URLを対応させる。分析と提案を混ぜない。参考が伸びていると断定できなくても、販売の分かりやすさの参考として選べる。

## 商品調査・取得

素材探索だけなら必要商品の名前・番号・言語を確認して進める。売れ筋選定や価格比較が依頼に含まれる場合は、通常直近30日、確認日の前日を終了日とし、対象条件のそろう成約を調べる。掲載日の時差が不明なら掲載日基準と記録。

- スニダンの人気順は人気順。売上数・実取引数のランキングと確認できない限り言い換えない。
- eBayのsold_countは当該出品の累計。completed_saleは売却済みを確認した出品。終了・在庫なしだけは成約でない。
- 未鑑定／PSA、言語、版、番号、状態、数量、送料・税をそろえる。目安は同条件3件以上・出品者2人以上。未達は明示し「売れ筋確定」にしない。
- PriceCharting等は二次資料。元のeBay出品を開いて照合できなければ一次確認済みとしない。一覧30行を月販30件にしない。
- `scripts/summarize_sales.py` の入力例・条件は [市場集計の仕様](market-data.md)。掲載サンプルの表示価格を集計する補助で、売上順位・利益保証は作らない。

公開ページで本文と画像URLを確認できる場合の商品画像保存の補助例。通常のHTTP取得を行う。取得できない場合はMuse側で用意したファイルを受け取る：

```powershell
python scripts/collect.py image --url "https://本文で確認した画像URL" --out "../制作物/assets/product01.webp"
```

ページ本文・画像を開いて確認後に採用。HTTP成功でも外枠だけなら取得成功でない。画像URLと商品ページURLを別々に残す。連続取得は2秒以上空け、同URLを重複取得しない。404・403等は通常経路を最大2回までとし、別の出典へ。sandboxによる接続不可は環境の正規の許可手順に従う。

使用可能な本人画像・許諾素材・商品説明用素材を優先。「公式」だけで再利用可能と判断しない。透かし・署名は消さない。条件不明のものは試作用とし、必要な場面を使える素材で構成する。

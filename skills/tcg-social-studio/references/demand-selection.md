# 需要から商品を選ぶ

v2.0 / 2026-11-12。価格表は仕入れ条件を調べるために使う。投稿対象は買い手が今求める商品と、その商品を買う理由から選ぶ。

## 需要の対象と期間

ゲーム、商品番号／BOX型番、言語、版、状態、鑑定、単位、対象国、客まで特定する。「コダックが人気」では広すぎる。英語版の販売量は日本語版需要の証明ではない。

直近30日を基本とし、可能なら直近7日とその前の7日を同条件で比較。途中の当日と完了日を混ぜない。需要確認の鮮度は原則7日以内、価格は制作当日（再利用は原則24時間以内）。これは運用の初期値で市場法則ではない。発売直後・急変時は当日更新する。値を変える場合は理由を残す。

| 入口 | 確認するもの | 混同しないこと |
|---|---|---|
| eBay | 同条件Sold、日付、数量、売り手、確認できる実売額 | 終了＝成約、累計sold＝月販、サンプル＝全市場 |
| TCGplayer | 販売量に基づく公式集計、公開成約、言語・版 | Market Priceが高い＝需要、日本語版＝英語版 |
| スニダン | 期間の分かる成立履歴、国内の動き | 国内人気＝海外需要、出品額＝自社売価 |
| Amazon日本 | 正しいカテゴリ・商品での販売順位、購入数表示と期間 | 順位を枚数へ換算、別版・付属品・パックを混入 |
| 自社の許可された記録 | 商品指定の問い合わせ、見積り、受注、リピート | 問い合わせ＝購入、別担当の成果＝自分の成果 |
| SNS | 商品への質問・保存等、視聴者の言葉 | 再生・いいね＝販売需要 |

4サイトの確認結果か取得不能理由を残す。全候補が4サイトすべてに存在する必要はない。

## 証拠と選定

実売の初期目安は同条件の独立した3件以上・売り手2者以上、複数日に継続していること。ただし最低限の材料であり、3件で「人気確定」ではない。別の販売資料、自社の具体的な需要、商品粒度・期間・国の一致した公式集計で補強する。

ランキング・価格上昇・出品数・再生数は候補発見の兆候。これだけで販売目的の完成案へ採用しない。月内の掲載30行を月販30件にしない。重複・鑑定品・まとめ売り・Best Offer実額不明を分け、取得範囲と除外を残す。同じURLを独立した2根拠に数えない。未取得は0にしない。

候補表には商品条件、客、指標、値、期間、取得日、一次／二次、URL、保存原本、観測範囲、除外、買う理由、他候補との比較、採否を書く。

採用条件は「対象客の購買行動の裏付け」「今買う具体的な利益」「他候補よりこの企画を選ぶ理由」。恣意的な点数を合算して人気を断定しない。根拠不足なら別候補へ。新商品は公式発表を根拠に情報紹介できるが、まだない実売を捏造しない。

## 安さと需要は別

需要があっても価格差が小さければ割安訴求には不適。「大きな差」の一律の正解はない。客の数量・予算・最低限の得・費用幅に照らした基準を候補比較前に記録し、差額と比率を両方評価する。送料・税・決済費用が増えた場合も考える。費用不明なら仕入れ利益を約束せず、市場差から見積りを比較する提案とする。それでも客の利益が説明できないなら採用しない。

却下商品は永久禁止にはしない。同じ案件で再提案するには前回以降の需要変化と欠点の解消を示す。古い例を当日の売れ筋に使い回さない。

基本3案は商品・客・訴求に意味のある差を持たせる。色違いや1カルーセルの3枚を3企画にしない。理由の欄には商品・時点・客・根拠・利益、ゴール欄には行動・送ってほしい内容・成果の確認方法を書く。DM数・売上を約束せず、案の採用と実際の成約を区別する。

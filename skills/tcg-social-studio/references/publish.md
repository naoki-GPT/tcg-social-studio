# 投稿する

**表の「投稿」タブで「投稿OK」にチェックが付いた行は、人が投稿を許可した行。** 改めて人に確かめず、自動で投稿する。チェックの無い行は、何があっても投稿しない。

## いつ表を見るか

頼まれるのを待たない。次の時に、自分で表を見る。

- `client.json` の `post_times` の各時刻（日本時間）。定期実行に登録しておく。
- 毎日の制作を始める前。

見るたびに、**チェックが付いていて「状態」が `投稿待ち` か `ストック` の行**を探す。あれば、作った日が古い順に **1回につき1本だけ** 投稿する。残りは次の時刻に回す（まとめて連続で出さない）。無ければ、何もせず終わる。

## 投稿の前に、その行を確かめる

1. 「投稿OK」にチェックがある。
2. 「状態」が `投稿済み` ではない（同じ行を2回出さない）。
3. 「完成物」のアドレスから、完成物のファイルを実際に取り出せる。
4. 「英語本文」が空ではない。
5. 価格を見せる投稿で、作ってから2日以上たっているときは、[商品を決める](research.md)の方法で価格を読み直す。大きく変わっていたら投稿せず、「気になる点」に「価格が変わったため未投稿（日付）」と書き足す。チェックはそのままにする。

1つでも満たさない行は投稿しない。理由を「気になる点」に書き足し、次の行を見る。

## 投稿する

- 投稿先は `client.json` の `instagram_handle` と、`platforms` に facebook があれば `facebook_page`。**両方に同じ完成物と同じ本文を出す。** ほかのアカウントには出さない。
- 画像・動画は「完成物」のファイルを、本文は「英語本文」の欄をそのまま使う。書き換えない。
- カルーセルは、ページの順番を完成物の番号どおりにする（「1枚目」〜「10枚目」の欄の順と同じ）。
- 途中で失敗して、出たかどうか分からないときは、もう一度出す前に、アカウントの最新の投稿を見て確かめる。

## 投稿した後、表に書く

| 欄 | 書くもの |
|---|---|
| 状態 | `投稿済み` |
| 投稿のアドレス | 実際に公開された投稿のアドレス（Instagram。Facebookにも出したら改行して続ける） |
| 公開日時 | 実際の公開日時（日本時間） |

書いたら読み戻し、アドレスを開いて、その投稿であることを確かめる。片方の媒体だけ失敗したら、「気になる点」に書き、次に表を見る時に失敗した側だけ出し直す。

## 数字を取る

投稿した次の日から、1日1回、`投稿済み` の行ごとに数字を取る。毎日の制作を始める前に行う。投稿から30日を過ぎた行は、週に1回でよい。

**取れる数字は全部取る。** 人がInstagramやFacebookのインサイト（投稿ごとの数字の画面）を開かなくても、「投稿」タブのその行で見られるようにするため。取るのは次の表の数字。媒体の数字の画面（アプリの「インサイトを見る」、またはMetaの数字の取得機能）で、その投稿について出ているものを全部。

| 「投稿」タブの欄 | 取る数字 | Metaの数字の名前（取得機能を使うとき） |
|---|---|---|
| 表示・再生 | 表示された回数（リールは再生回数） | Instagram `views`／Facebook `post_impressions`・動画は `post_video_views` |
| リーチ | 見た人の数（同じ人は1回） | Instagram `reach`／Facebook `post_impressions_unique` |
| いいね | いいね（Facebookはリアクションの合計） | `likes`／`post_reactions_by_type_total` |
| 保存 | 保存された数 | `saved` |
| コメント | コメントの数 | `comments` |
| シェア | シェア・送信された数 | `shares` |
| プロフィールへのアクセス | この投稿からプロフィールを見た数 | `profile_visits` |
| フォロー | この投稿からフォローされた数 | `follows` |
| 国（多い順） | 見た人・反応した人の国の上位3つと割合（例：`US 42%／GB 11%／CA 8%`） | 投稿ごとの内訳が出るときだけ |
| 年代（多い順） | 年代の上位3つと割合（例：`25-34 38%／18-24 27%／35-44 20%`） | 投稿ごとの内訳が出るときだけ |
| 買う言葉のコメント | コメントのうち、買う言葉が入っているものの数と、その原文を2つまで（例：`3件：Price? / Still available?`）。買う言葉は、価格を聞く（`Price?` `How much?`）、頼めるかを聞く（`Still available?` `Are any left?`）、買い方・送料を聞く（`How do I buy?` `Shipping to UK?`）、DMしたと言う（`DM sent` `DMed`）もの。絵文字だけ、ほめ言葉だけ、プレゼント企画への応募は数えない | — |
| 相談（DM） | 合言葉（`client.json` の `contact.keyword`）が入ったDMのうち、その投稿の商品名が入っているものの数。商品名が無く、どの投稿か分からないDMは、どの行にも数えず、「取れなかった数字」に `DM ○件は投稿不明` と書く。DMを読むだけで、返信はしない | — |

書き方：

- **InstagramとFacebookの両方に出した行は、1つの欄に2行で書く**（`IG 1,234` の改行 `FB 56`）。片方にしか無い数字は、その媒体の行だけ。足し算しない。
- 「数字を取った日時」に、取った日時（日本時間）を書く。毎回、新しい数字で上書きする。前の数字は「数値の記録」タブに残っている。
- 取れなかった数字は欄を空にし、「取れなかった数字」に、名前と理由を短く書く（例：`FB 保存（Facebookには無い）`、`国・年代（この投稿ごとには出ない）`）。0 を入れない。前の日に取れた数字を、取れなかった日に消さない。
- **国と年代が投稿ごとには出ず、アカウント全体の数字しか出ないとき**は、欄の先頭に `【アカウント全体・直近7日】` と付けてから書く。投稿ごとの数字のように見せない。
- 取った数字は全部、「数値の記録」タブにも1つにつき1行で足す（[表の書き方](sheet.md)）。
- 数字を取るために、投稿の設定を変えたり、広告を出したり、お金のかかる機能を使ったりしない。

## しないこと

- チェックの無い行の投稿。
- 「投稿OK」の欄の書き換え（投稿した後も、チェックはそのままにする）。
- DMやコメントへの返信・送信。
- 投稿済みの投稿の削除や本文の書き換え（頼まれたときだけ行う）。

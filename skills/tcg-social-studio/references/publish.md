# 投稿する

**表の「投稿」タブで「投稿OK」にチェックが付いた行は、人が投稿を許可した行。** 改めて人に確かめず、自動で投稿する。チェックの無い行は、何があっても投稿しない。

## いつ表を見るか

頼まれるのを待たない。次の時に、自分で表を見る。

- `client.json` の `post_times` の各時刻（日本時間）。定期実行に登録しておく。
- 毎日の制作を始める前。

見るたびに、**チェックが付いていて「状態」が `投稿待ち` か `ストック` の行**を探す。あれば、作った日が古い順に **1回につき1本だけ** 投稿する。残りは次の時刻に回す（まとめて連続で出さない）。無ければ、何もせず終わる。

## 投稿の前に、その行を確かめる

1. 「投稿OK」にチェックがある。
2. 「状態」が `投稿済み` ではない（同じ行を2回出さない）。
3. 「完成物」のアドレスから、完成物のファイルを実際に取り出せる。
4. 「英語本文」が空ではない。
5. 価格を見せる投稿で、作ってから2日以上たっているときは、[商品を決める](research.md)の方法で価格を読み直す。大きく変わっていたら投稿せず、「気になる点」に「価格が変わったため未投稿（日付）」と書き足す。チェックはそのままにする。

1つでも満たさない行は投稿しない。理由を「気になる点」に書き足し、次の行を見る。

## 投稿する

- 投稿先は `client.json` の `instagram_handle` と、`platforms` に facebook があれば `facebook_page`。**両方に同じ完成物と同じ本文を出す。** ほかのアカウントには出さない。
- 画像・動画は「完成物」のファイルを、本文は「英語本文」の欄をそのまま使う。書き換えない。
- カルーセルは、ページの順番を完成物の番号どおりにする。
- 途中で失敗して、出たかどうか分からないときは、もう一度出す前に、アカウントの最新の投稿を見て確かめる。

## 投稿した後、表に書く

| 欄 | 書くもの |
|---|---|
| 状態 | `投稿済み` |
| 投稿のアドレス | 実際に公開された投稿のアドレス（Instagram。Facebookにも出したら改行して続ける） |
| 公開日時 | 実際の公開日時（日本時間） |

書いたら読み戻し、アドレスを開いて、その投稿であることを確かめる。片方の媒体だけ失敗したら、「気になる点」に書き、次に表を見る時に失敗した側だけ出し直す。

## 数字を取る

投稿した次の日から、1日1回、投稿ごとの数字（表示・再生、いいね、保存、コメント）を取る。毎日の制作を始める前に行う。

- 取った数字は「数値の記録」タブに、1つの数字につき1行で足す。
- 「投稿」タブの右端の欄には、いちばん新しい数字を書く。
- 取れなかった数字は空のままにする。0 を入れない。
- 「相談（DM）」は、合言葉つきのDMが来た数。分かる範囲で書く。

## しないこと

- チェックの無い行の投稿。
- 「投稿OK」の欄の書き換え（投稿した後も、チェックはそのままにする）。
- DMやコメントへの返信・送信。
- 投稿済みの投稿の削除や本文の書き換え（頼まれたときだけ行う）。

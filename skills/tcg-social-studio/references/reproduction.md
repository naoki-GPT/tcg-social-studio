# 参考の測り方

参考投稿は、解説文や記憶ではなく、保存した実物を開いて測る。測った値は制作フォルダの `02_分解.md` に表で書き、その値で作る。

**主力の型（[型カード](types.md)のA〜E）は、型カードの決めが先。** 参考を測るのは、何をどの順で見せているか、文字の内容、文字が出る時刻、価格が出る時刻、行動の案内が出る場所を知るため。参考に揺れやフラッシュや細かいカットがあっても、それは写さない。参考が価格を出していなくても、こちらは `price_display` のとおりに出す。

補助の型で、何をどこまで合わせるかは、参考帳の「必要な素材」で変わる。

| 必要な素材 | 測るもの | 合わせるもの |
|---|---|---|
| カード画像と文字だけで作れる | 下の1〜4の全部 | 配置・寸法・色・質感・動き・時刻まで |
| 実物の映像が要る | 構成、各場面の長さ、文字の内容と出る時刻、切り替え方、音の入り方 | 構成とテンポ。見た目は[型カード](types.md)で決める |

## 1. 全ページ・全編がそろっているか

`reference/media-manifest.json` の枚数と、投稿に表示されている枚数を合わせる。そろっていなければ作り始めない（[素材を取ってくる](assets.md)）。

## 2. 画像・カルーセルを測る

1ページずつ、次を書く。位置と大きさはピクセルで測る（画面に対する割合を併記してよい）。

| 測るもの | 書き方の例 |
|---|---|
| 見出しの全文、小さい文字、行動の案内 | 原文のまま |
| 商品・価格・条件 | 何が、いくつ、どこに |
| 文字の位置・幅・高さ、行の間隔 | `見出し：上から 96px、幅 880px、2行` |
| 書体の種類・太さ・縁取り・影・グラデーション | `極太ゴシック、黄から橙のグラデーション、黒の縁取り 6px` |
| 背景の色・模様・光・飾り | `紺、右上から斜めの光、金の細い枠` |
| 商品の大きさ・傾き・まわりの余白 | `カード：幅 420px（画面の39%）、右に3度` |
| 読む順番と、前後のページとのつながり | `1枚目で問い、2枚目で答え` |

- **元と同じ枚数・同じ順番が既定。** 表紙・本文・案内の3枚へ縮めない。
- 参考に行動の案内のページが無ければ、勝手に1枚足さない。案内は本文に書く。足す必要があるときは、足したことを表の「気になる点」に書く。
- 見出しの立体感（グラデーション・縁取り・影）と、背景の光や飾りも、寸法と同じく合わせる対象。
- 書体が特定できないときは、近い書体で質感を寄せ、「気になる点」に書く。

## 3. 動画を測る

動画は、次の5つを別々の時間の流れとして書く。1つの表に混ぜない。

| 流れ | 書くもの |
|---|---|
| 映像のカット | 各カットの開始と終了（コマ番号か秒）、映っているもの、構図、切り替え方 |
| 文字（テロップ） | 文字の内容、出る時刻と消える時刻、場所、書体、縁取りや影、強調される語 |
| 商品・カメラの動き | 位置・大きさ・傾き・濃さの、始まり・途中・終わり。速さの変わり方 |
| 効果 | フラッシュ・光・ぼかし・揺れなど。始まりと終わり、強さ、何にかかるか |
| 音 | 声・無音・BGM・効果音の始まりと終わり。どの動きと同時か。聞けた範囲 |

- カットは映像の切れ目。文字が変わっただけの所をカットに数えない。
- 参考が1つの長いズームなら、文字が変わるたびにズームをやり直さない。参考にハードカットがあれば、同じ商品でもカットを入れる。
- 参考に無いタイピング・ズーム・点滅・締めの画面を足したら、足したことを「気になる点」に書く。

カットの候補は道具で出せる。出てくるのは候補で、確定ではない。

```powershell
python scripts/analyze_reference_video.py <参考.mp4> --out <制作フォルダ>/checks/analyze
```

候補の前後のコマを実際に開き、本当の切れ目だけを残す（文字だけの変化や手の動きは外す）。動きの瞬間を合わせるときは、候補の時刻の前後約0.3秒を1コマずつ見る。音を聞けなかったときは、音は「未確認」と書く。

## 4. 測った値で作る

- **作る指示に実測値を入れる。** 「見出しを上に、商品を中央に」のような役割だけの指示で作らない。位置・幅・高さ・間隔の数字で作る。
- **中身を替えても、枠は替えない。** 他社の店名・実績・価格は自社の内容に替えるが、替えた内容は元の配置と寸法の中に収める。
- **商品の数が元より少ないときは、拡大して余白を均す。** 元の配置枠いっぱいに商品を大きくし、左右の余白と間隔を均等にする。価格札などは商品に比例させる。見出し・帯・脚注などページの骨格は実測のまま。変えた値は `02_分解.md` に、前と後の数字で書く。
- 目安：主な要素の位置・幅・高さの差は画面の2%以内。カットと文字の時刻は1コマ以内。これはずれを見つけるための目安で、数字が合えば合格という意味ではない。

## 5. 実写の参考を、カード画像で作り替えるとき

「実物の映像が要る」参考は、次だけを測って借りる。

1. **構成**：何を、どの順で見せているか（例：1枚目で引きつける → 1枚ずつ7枚 → 最初の1枚に戻る）。
2. **テンポ**：1つを見せる長さ（例：約2秒ごとに次の1枚）、全体の長さ。
3. **文字**：何を書いているか（カード名・番号・絵師、枚数、価格など）、いつ出るか。
4. **切り替え**：ハードカットか、流れるように替わるか。
5. **音**：切り替えに音があるか、BGMの雰囲気。

実物の映像の代わりに置くもの：

| 参考の映像 | 置き換え |
|---|---|
| 手に持ったカードを1枚ずつ | カード画像を画面いっぱいに1枚ずつ。入り方に動きを付ける（[作り方](production.md)） |
| 机いっぱいのカードの束 | カード画像を格子や扇の形にたくさん並べ、ゆっくり流す |
| BOXの山 | BOXの画像を段に並べ、数を数字で見せる |
| 開封・梱包の手元 | 作り替えない。`footage_folder` に実写があれば型Eで作る。無ければ別の参考を選ぶ |

実物の反射や量感には届かない。その差は表の「気になる点」に書く。

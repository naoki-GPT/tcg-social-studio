# 全ページ・全編を再現する仕様

v2.3 / 2026-11-13。参考の解説文ではなく実メディアを設計元にする。全取得、分解、再制作、対照検品を一続きに行う。

## 取得と完全性

台帳ID→元投稿URL→投稿ID→子投稿順序→保存ファイルを一対一に結ぶ。原JSON・取得日時・元の枚数・各ファイルのハッシュ・実寸を記録。期限付きCDN URLだけを配布しない。利用者側で開ける原本または本人用の参照フォルダを用意し、全ファイルを開けることを確かめる。

カルーセルは[素材入力](media-input.md)の `files` を元の順序で使う。先頭画像や解像度違いを全枚としない。元の期待枚数が不明な場合は全枚確認を通さない。[取り込みスクリプト](../scripts/import_reference_media.py)で全ファイルを保存できる。ファイルのコピー成功と、元投稿との一致・内容の全編確認は別。

## 全ページの分解

各ページの①見出し全文②説明・小文字・CTA③商品・価格・条件④背景⑤文字の座標と最大幅⑥フォント／太さ／斜体／縁取り／影／行間⑦商品領域の比率・回転・余白⑧読む順序⑨前後ページのつながりを記録する。座標は0〜1の正規化値と実ピクセルを併記できる。

カルーセルの既定は元と同じ枚数・順番。共通の表紙・本文・CTAの3枚へ圧縮しない。違う商品数や自社CTAを加える必要があれば、増減と理由を明示する。元にCTAがない場合、元を見た事実としてCTAを書き足さない。

REF-005型の例：商品左／価格右／推移下の構図だけでは不足。紺の色域・黄の見出し・黒い斜線背景・白い周縁・カードの大きさ・価格の太さ・赤い下げ幅・ページの反復規則まで実物から採寸する。過去の観察メモはヒントであり採寸値ではない。

## 動画は別々の時間軸で分解

| トラック | 必須の記録 |
|---|---|
| 映像カット | 開始・終了フレーム（終了は含まない）、素材、構図、切替方法 |
| テロップ | 文字列、出現・消失フレーム、語単位強調、場所、書体、縁・影 |
| 商品／カメラ | 位置・縮尺・回転・不透明度の始点／中間／終点、速度の変化 |
| 効果 | フラッシュ・光・ブラー・揺れ等、開始・終了・強度・対象レイヤー |
| 音 | 発話・無音・BGM・SEの開始／終了、強調と同期、聞き取れた範囲 |

カットは映像の切れ目。字幕・強調語の切替と同一視しない。同じ商品でも元にハードカットがあれば再現する。元が連続ズームなら字幕変更時にズームをやり直さない。元映像を全部同じパンに置き換えない。

## Cutmatchから取り入れる確認の粒度

毎フレームの差分、色分布の変化、特徴点移動によるズーム・平行移動・回転を測る。全体に加え上部と端の領域を使い、商品の動きをカメラ移動と誤認しにくくする。自動解析は候補検出であり意味の判定ではない。

`analyze_reference_video.py`は4fpsの全編一覧、候補境界前後4フレーム、毎フレームの動き指標を保存する。真の切れ目を実画面で確認し、字幕だけの変化や手の動きをカットから外す。動作の瞬間を合わせるときは候補時刻の前後約0.33秒を元fpsの1フレーム刻みで追う。

文字は全体縮小図と原寸の文字領域を両方見て、幅・高さ・基準位置を調整する。自動推定のフォント名やキーフレームを確定値としない。特徴点でカメラ運動と編集ズームを区別できない場合は不明と記録する。

VFR（可変フレームレート）は実際の表示時刻で扱う。解析用CFRへ変換した場合、元の時刻への対応を保存し、元fpsと同じとは言わない。映像・音声の短縮や不足をループで埋めない。

## 制作と照合

[分解表](../templates/reference-breakdown.example.json)を埋め、それを[作り方カード](recipe-cards.md)のslides/timeline/座標へ移す。`build_from_recipe.py --card recipe-card.json --content content.json --out production` で編集用データを作る。分解表をそのまま渡すコマンドではない。自社の商品、数字、導線に置換してデザインを実装する。汎用テンプレートにある固定4秒は使わない。

比較は同じ画面比率で、静止画なら全ページを一対一、動画なら同時刻で全編を同期。境界前後1フレーム、各動きの始点・中間・終点を開く。拡大縮小やページ欠落があれば数字だけの検査に合格しても差し戻す。

初期の幾何目安は主要要素の位置／幅／高さの差が画面の2%以内、切替とテロップは1フレーム以内。これは自動合格点ではなくズレを見つける目安。見出しの印象、行分け、背景、光、速度、読みやすさ、最後の案内は目視を必要とする。参考自体が読みにくい場合の改善は意図した差として残す。

原書体・実写素材・音の使用条件が揃わない場合は、近似／置換／未再現を区別して報告する。再現指定なのに大きく異なる部分を「意図した差」と命名するだけで合格にしない。必要な事実・ブランド置換と、制作都合の省略を分ける。

## 実測から外さないための決め（2.3.0で追加。共通試作 trial-001 の是正から）

- **制作指示に実測値を入れる。** 制作を他者・他工程へ渡すときは、骨格や役割だけの指示にしない。各ページの要素ごとの位置・幅・高さ・間隔をピクセルで測った実測表を先に作り、指示書へその値を入れる。実測表のない再現指示は、その時点で不足として扱う。
- **内容の差し替えは再現を免除しない。** 他社の実績・条件・ロゴ・価格は自社／試作用の内容へ差し替えるが、差し替えた内容は元のレイアウトと寸法の中に収める。役割だけを借りて組み直したものは再現と呼ばない。
- **要素が少ないときは拡大して余白を均す。** 商品数などが元より少ない場合、元の要素サイズのまま余白を残さない。元の配置枠（ゾーン）いっぱいに要素を拡大し、左右の余白と要素の間隔を均等に整える。価格札などの付随要素は、主要素に比例させて拡大する。見出し・帯・脚注などページの骨格は実測のまま維持する。この調整は実測表へ変更前後の値とともに記録し、無断の逸脱にしない。
- **質感も再現の対象にする。** 見出しのグラデーション・縁取り・影などの立体処理と、背景の光・リボン・きらめき等の装飾は、寸法と同じく再現対象に含める。元の書体が特定できない場合は近似の書体で質感を寄せ、未解決の差分として明示する。同一と書かない。
- **納品は並べた比較で示す。** 全ページについて、元と完成品を同寸で並べた比較画像を添え、合った項目と残る差分を先に報告する。近似で済ませた部分を、報告なしに完成として渡さない。

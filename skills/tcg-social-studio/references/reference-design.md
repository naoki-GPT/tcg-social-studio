# 参考の再現と検品

版2.0／2026-11-12。指定された参考は[全ページ・全編の再現仕様](reference-reproduction.md)を優先する。旧版の「同じ商品を絶対に再登場させない」は撤回。参考に実在するハードカット・再登場は、観察フレームを記録して再現する。

1. [実物確認済みの索引](verified-reference-map.md)でIDとURLを照合。保存済みの全メディアを開く。旧メモ・本文・先頭画像だけでは確認完了ではない。
2. 背景、装飾、光、影、罫線、書体、太さ、縁取り、字間、改行、商品寸法と座標を記録。元書体が分からなければ近似と書き、未解決差分に残す。
3. 静止画は全枚を同順で対応。動画はカット・字幕・動き・効果・音を別トラックにする。字幕が変わるだけで商品を消さない。参考の同じ商品へのカットは `reference_cut:true` と実際の観察内容を併記。
4. 元参考にないタイピング、ズーム、点滅、締めスライドを勝手に加えない。販売導線を足す際は、まず本文へ入れ、映像に追加する変更は理由を記録する。
5. [作り方カード](recipe-cards.md)から編集元を作る。プリセットで足りない効果は専用HTMLまたは動画編集で実装。似た効果の選択だけでは完成にしない。
6. 全スライドを対応順で、動画は同じフレーム位置で比較する。始点・中間・終点、全境界の前後1フレームも調べる。比較一覧だけでは速度・間・音の一致は分からないため、同期した全編比較を行う。
7. 商品写真と自社の事実へ置換した差を記録。競合の在庫、顧客実績、発送日、最安等の主張を自社へコピーしない。人物・倉庫を合成商品へ置き換えた映像は、その差を消さず明記する。

`templates/story`・`templates/reel`は汎用の試作用。そこで固定された構図や秒数を忠実再現の根拠にしない。HTMLの動きだけでなく完成MP4を検査する。生成した背景や手持ち合成を、実在庫・傷・ホロの現物証拠にしない。

完成判定は[acceptance.md](acceptance.md)。検査成功は、需要の証明や美しさの自動採点ではない。

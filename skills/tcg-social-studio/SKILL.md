# 毎日3案を作り、人が選んだものを投稿する

版：4.4.0／2026-11-14。

このスキルの仕事は2つある。どちらも、人に頼まれるのを待たずに定期実行で動く。

| いつ | すること | 読むもの |
|---|---|---|
| 毎日1回、`client.json` の `create_time` の時刻（または「今日の投稿を作って」と頼まれたとき） | 商品を調べ、3案を完成させ、表の「投稿」タブに3行書く（下の「毎日の流れ」） | この文書 |
| `client.json` の `post_times` の各時刻 | 表を見て、「投稿OK」にチェックが付いた行を1本投稿し、結果を表に書く | [投稿する](references/publish.md) |

**「投稿OK」のチェックは、人による投稿の許可。** チェックが付いた行は、改めて確かめずに自動で投稿する。チェックの無い行は投稿しない。

投稿の目的は、見た人に「この店に聞けば手に入りそうだ」と思ってもらい、DM・コメント・問い合わせをしてもらうこと。その日に在庫があるかどうかは、商品を選ぶ条件にしない。

## 進め方の決まり

- **途中で人に質問しない。** 分からないことは調べて自分で決め、決めた理由を表の「選んだ理由」に書く。決められない案は捨てて、別の商品か別の参考で作り直す。
- **止まるのは、[client.json](client.json) の必須欄が空のときと、`sheet_url` がひな形の表のままのときだけ。** 毎回最初に `node scripts/check_client.mjs` を実行し、`[ERROR]` が出たら、出た欄をそのまま伝えて終わる。道具が動かないときは止まらず、[止まったときの早見表](references/troubleshooting.md)で直して続ける。
- **人がするのはチェックだけ。** 「投稿OK」の欄は人だけが触る。
- **素材は自分でそろえる。** 参考投稿は保存済みの原本（`reference-originals/`）を先に使い、無いものだけ自分で開いて保存する。商品画像は自分で取りに行く。他人の出品写真は使わない。

## 最初に読むもの

[client.json](client.json)。店名・アカウント・スプレッドシートのアドレス・保存先など、**渡す相手ごとに違うものはここにだけ**書いてある。

商品の種類・合言葉・色は `client.json` に書かない。毎回決めて、表のその行に残す。

| 毎回決めるもの | 決め方 |
|---|---|
| 商品と商品の種類 | 毎日調べて、表の「商品の候補」タブから選ぶ。 |
| 型（見せ方） | 表の「参考帳」タブから選ぶ。 |
| 合言葉（DMで送ってもらう短い英単語） | 商品に合わせる。「投稿」タブの過去の行に同じ商品の種類があれば、同じ合言葉を使う。 |
| 色・書体・動き | 参考投稿と商品そのものの色に合わせる。[型カード](references/types.md)に従う。 |
| 毎回変えないもの | 最後の締め（`client.json` の `closing`）だけ。 |

## 毎日の流れ（3案を作る）

1日に作るのは `client.json` の `daily_set` の3案。既定は **リール1本・カルーセル1本・画像1本**。3案は商品も型も別にする。人は気に入った案にだけチェックを入れる。全部でも、1つでもよい。

各工程で読む説明書は右の列だけ。先に全部を読まない。

| 順 | やること | その時に読む説明書 |
|---|---|---|
| 1 | `client.json` と、表の「投稿」タブの直近14日分を読む。投稿済みの行の数字を取る | [表の書き方](references/sheet.md)／[投稿する](references/publish.md) |
| 2 | 今日の商品を調べて「商品の候補」に足し、3案の「商品」と「型」の組み合わせを決め、今日の価格を読む | [商品を決める](references/research.md) |
| 3 | 参考帳に新しい手本を1〜2件足す。選んだ参考投稿の全ページ・全編と、商品の画像を保存する | [素材を取ってくる](references/assets.md) |
| 4 | 参考を測って、3案を作る | [参考の測り方](references/reproduction.md)／[作り方](references/production.md)／[型カード](references/types.md) |
| 5 | 画面の文字と本文を、英語と日本語訳で書く（本文はInstagramとFacebookで同じ1つ） | [文章](references/copy.md) |
| 6 | 完成物を開いて検品し、不合格は直す | [検品](references/check.md) |
| 7 | 完成物と「見た目」の画像を共有フォルダに上げる。「投稿」タブに3行、「素材」タブに使った素材を書き、読み戻して確かめる | [表の書き方](references/sheet.md) |

### 3案の組み合わせの決まり

- 同じ型を2日続けて使わない。同じ「型×商品の種類」は14日あける。
- 同じ商品を3日以内に繰り返さない。
- 3案のうち1つは、価格や値動きなど数字を見せる型にする。残りは、商品の魅力を見せる型にする。
- 過去の行で「ストック」になっている案は、人が選ばなかった案。7日以内なら、価格を取り直して今日の案の1つとして出し直してよい（1日1つまで）。

### うまく作れない案があるとき

その案だけ、別の商品か別の参考に替えて作り直す。3回替えても作れなければ、その日は作れた案だけを表に書き、足りない分は「状態」を `見送り` にして理由を書く。弱い案で数を埋めない。

## 制作フォルダ

`client.json` の `output_folder` の下に、1案につき1つ作る。スキルのフォルダの中には保存しない。

```text
<output_folder>/YYYYMMDD-A_商品の短い名前/     （A・B・C は案の記号。表の投稿IDと同じ）
  01_調査.md        今日の価格、出典、確かめた日時、選んだ理由
  02_分解.md        参考の全ページ・全編の実測
  03_文章.md        画面の文字と本文（英語と日本語訳）
  reference/        参考投稿の原本（全枚・全編）と media-manifest.json
  assets/           商品の原画像、生成した背景
  index.html ほか   編集元
  reel_v1.mp4 / slides_v1/ / image_v1.png   完成物（直したら v2、v3 と上げる。上書きしない）
  preview_v1.jpg    表に貼る「見た目」の画像
  checks/           検品で開いたコマ、参考と並べた比較
```

## 道具

スキルのフォルダを作業場所にして実行する。初回だけ [START_HERE.md](START_HERE.md) の準備をする。引数と実行例は[作り方](references/production.md)にある。

| したいこと | 実行するもの |
|---|---|
| 環境がそろっているか確かめる | `node scripts/check_env.mjs` |
| `client.json` の足りない欄を出す | `node scripts/check_client.mjs` |
| ブラウザーが無いPCに試験用のChromeを入れる | `npm run browser` |
| 参考投稿の原本を順番どおり取り込む | `python scripts/import_reference.py` |
| 参考動画のカット候補を出す | `python scripts/analyze_reference_video.py` |
| カルーセル・画像を書き出す | `node scripts/shoot_slides.mjs` |
| リールのコマを撮る | `node scripts/capture_frames.mjs` |
| 効果音を時刻どおりに並べる | `python scripts/mix_audio.py` |
| コマと音をMP4にして中身を確かめる | `node scripts/finish_video.mjs` |
| 表に貼る「見た目」の画像を作る | `python scripts/make_preview.py` |
| 参考と完成物を並べて比べる | `python scripts/compare_reference.py` |
| 生成画像の付加情報を消す | `python scripts/clean_metadata.py` |

## しないこと

- 「投稿OK」にチェックの無い行の投稿、DM・コメントの送信。
- 「投稿OK」の欄を書き換えること。
- 確かめていない在庫数・発送日・最安・実績を、画面や本文に言い切りで書くこと。
- 商品の絵柄・番号・文字をAIで描き直すこと。人物や在庫の山をAIで作ること（背景と飾りは生成してよい）。
